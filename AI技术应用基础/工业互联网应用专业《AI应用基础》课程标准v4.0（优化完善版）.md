### （二）课程性质与定位

《AI应用基础》是工业互联网应用专业的**核心专业课程**，面向专科一年级新生设计。课程总学时48（理论24+实习24），总学分3分。

**课程定位**：

1. **零基础入门**：为没有AI基础的大一新生设计，强调循序渐进、难度递进
2. **工程驱动**：以真实工业问题为核心驱动，先解决问题后理论深化
3. **技术融合**：传统ML→深度学习→大模型→智能体的完整路线
4. **岗位支撑**：为四大工业岗位培养"数据处理→模型开发→系统集成"的核心能力

### （三）课程基本教学理念

#### 1. **工程实践优于理论**

- 优先讲"怎么做"（工程操作），再深化"为什么"（理论原理）
- 每个知识点以真实工业问题为引入
- 学生通过改变超参数观察模型效果，建立直观理解

#### 2. **适应大一新生的递进设计**

- **初级阶段**（第1-4周）：夯实数据处理、传统ML基础
- **中级阶段**（第5-8周）：逐步深化到深度学习、计算机视觉
- **高级阶段**（第9-12周）：融合大模型、NLP、多智能体
- 每个阶段建立成功体验，增强学生学习信心

#### 3. **难度自适应与差异化**

- **必修项目**（每周工单）：基础框架，确保掌握
- **进阶项目**（可选）：性能优化、创新应用，为优秀学生提供挑战
- **补强资源**：提供数学基础复习、编程技能速成课程

#### 4. **零硬件与具体化虚拟产线**

- 不依赖额外硬件（树莓派、传感器等）
- 提供**具体的虚拟产线工具、API、示例数据**
- 学生在个人笔记本上完整体验工业AI应用全流程

#### 5. **模型可解释性与可信AI**

- 强调模型结果的可解释性、鲁棒性、公平性
- 关注模型部署、实时推理、成本优化的工程实际
- 培养学生的AI伦理意识与职业责任

### （四）对接"1+X"证书

- **AI应用实践职业技能等级证书**（中国信息技术化教育认证）
  - 初级：完成M1-M3模块，掌握传统ML与基础深度学习
  - 中级：完成M4模块，掌握NLP与大模型应用
  - 高级：完成M5模块，掌握多智能体系统

## 二、教学目标

### （一）知识目标

1. **掌握数据科学基础**
   
   - 理解数据清洗、探索分析、特征工程的工作流程
   - 掌握Pandas数据处理与可视化

2. **掌握传统机器学习**
   
   - 理解监督学习与无监督学习原理
   - 掌握分类、回归、聚类等常用算法
   - 掌握模型评估指标（精确率、F1、MSE、R²等）

3. **掌握深度学习基础**
   
   - 理解神经网络基本原理（激活函数、反向传播）
   - 掌握CNN、RNN、LSTM在工业中的应用
   - 理解Transformer架构与大模型基础原理

4. **掌握计算机视觉技术**
   
   - 理解图像分类、物体检测的基本方法
   - 理解迁移学习与多模态视觉大模型

5. **掌握自然语言处理**
   
   - 理解文本处理与特征提取
   - 掌握LLM调用、Prompt工程、RAG系统

6. **掌握多智能体与强化学习**
   
   - 理解智能体架构与多智能体协调
   - 掌握基础强化学习算法（Q-Learning、DQN）

### （二）能力目标

1. **数据处理能力**：能够使用Pandas完成数据清洗、EDA、特征工程

2. **传统ML模型开发能力**：能够独立使用Scikit-learn、XGBoost构建和评估模型

3. **深度学习开发能力**：能够使用TensorFlow/PyTorch构建基础神经网络、CNN、LSTM

4. **计算机视觉应用能力**：能够使用预训练模型进行图像分类、物体检测

5. **大模型应用能力**：能够调用LLM API、设计Prompt、构建RAG系统

6. **智能体开发能力**：能够设计LLM驱动的智能体、实现多智能体系统

7. **工业AI系统集成能力**：能够整合多种AI技术构建完整系统

### （三）素质目标

1. **职业素养**：严谨的工程精神、AI伦理意识、团队协作能力
2. **学习能力**：自主学习、问题解决、创新思维
3. **专业竞争力**：扎实的AI基础、工业应用经验、持续学习能力

### （四）研究与创新

1. 轻量化深度学习在边缘计算的应用
2. 大模型在工业场景的创新应用
3. 多智能体系统的协调与优化

### （五）可持续发展

1. 模型能效与环保（量化、蒸馏等轻量化技术）
2. AI伦理与社会责任
3. 持续学习与技术更新

## 三、教学内容

### （一）教学方式

#### 1. **理实一体"讲演做"教学法**

- **讲**（15分钟）：讲解算法原理、工业应用背景
- **演**（15分钟）：使用真实工业数据演示代码实现、结果分析
- **做**（20分钟）：学生改变参数、进行自主实验、记录现象

#### 2. **虚拟产线与真实场景结合**

- 虚拟产线数据生成工具
- 真实工业数据集（每个阶段提供标注数据）
- 企业合作数据（可选）

#### 3. **工单项目制与难度梯度**

- **必修工单**：每周基础项目，掌握框架
- **进阶工单**：可选项目，性能优化、创新应用
- 每个工单设"及格"和"优秀"两个评估标准

#### 4. **分层教学与进度自适应**

- **A班**（快班）：深入理论、挑战项目
- **B班**（常规班）：平衡理论与实践、稳步推进
- **C班**（补强班）：强化基础、延缓进度
- 学生可根据进度灵活调整

#### 5. **同伴学习与项目答辩**

- 小组讨论、代码审查
- 每周工单小组展示与答辩
- 同伴互评机制

#### 模块详细内容

##### **模块M1：数据处理与特征工程基础（第1-2周，8课时）**

*难度标记：⭐⭐（低—中）*

**核心概念**：数据清洗→EDA→特征工程→特征选择的完整流程

**学习内容**：

- 数据清洗：缺失值、异常值、重复值处理
- 探索性分析：单变量分布、相关性、时序趋势
- 特征工程：数值特征（缩放、分桶）、文本特征（TF-IDF）
- 特征选择：方差分析、相关性、特征重要性

**工业应用**：传感器数据质量评估、特征库设计

**工单项目**：

- M1-1：传感器数据清洗与质量评估（及格标准：缺失值处理率≥95%）
- M1-2（进阶）：最优特征组合设计（优秀标准：特征个数减少30%，性能不降低）

---

##### **模块M2：机器学习与神经网络基础（第3-6周，16课时）**

*难度标记：⭐⭐⭐（中—高）*

**细化设计**（相对于v3.0的改进）：

**第3-4周（8课时）：传统ML与集成学习**

- 第3周（4课时）：分类基础（逻辑回归→决策树）→ **取消SVM**（降低复杂度）
  
  - 工单：故障分类预测（及格：准确率≥70%）

- 第4周（4课时）：集成学习（随机森林→XGBoost）→ **深化超参数调优**
  
  - 工单：XGBoost参数优化（及格：F1分数≥0.70，优秀≥0.85）

**第5-6周（8课时）：神经网络与序列模型**

- 第5周（4课时）：神经网络基础（MLP、激活函数、反向传播）→ **重点讲解反向传播**
  
  - 工单：MLP分类模型（及格：准确率≥75%）
  - 补强资源：神经网络可视化工具、练习题

- 第6周（4课时）：CNN与LSTM **选择其一深入**（不同班级选择不同路线）
  
  - **A班**：CNN→基础卷积原理 → 简化AlexNet实现
  - **B班**：LSTM→时间序列预测 → 实时告警系统
  - **C班**：补强班→神经网络复习 → 简化的MLP练习

**软硬件工具**：Scikit-learn、XGBoost、TensorFlow/PyTorch、Pandas

**工单项目汇总**：

- M2-1：故障分类预测（传统ML）
- M2-2：XGBoost参数优化
- M2-3：CNN图像识别 或 LSTM时序预测（选择其一）

---

##### **模块M3：计算机视觉与图像识别（第7-8周，8课时）**

*难度标记：⭐⭐⭐（中—高）*

**优化设计**：

- 减少理论讲解，强化**预训练模型+迁移学习**的实际应用

- 第7周（4课时）：迁移学习基础 → ResNet缺陷分类
  
  - 工单：产品缺陷分类（及格：准确率≥75%）

- 第8周（4课时）：物体检测 → YOLO缺陷定位 → 视觉大模型（GPT-4V）图像理解
  
  - 工单：工业缺陷检测系统（及格：mAP≥0.60）

**软硬件工具**：OpenCV、TensorFlow/PyTorch、YOLO、OpenAI Vision API

---

##### **模块M4：NLP与大模型应用基础（第9-10周，8课时）**

*难度标记：⭐⭐⭐（中—高）*

**优化设计**：

- **第9周（4课时）**：LLM调用 + Prompt工程
  
  - NLP基础（去停用词、分词）→ LLM API调用 → Prompt工程
  - 工单：LLM故障诊断系统（及格：准确率≥75%）
  - 补强资源：Prompt工程最佳实践教程

- **第10周（4课时）**：RAG系统 + 思维链
  
  - RAG工作流 → 向量化与检索 → 增强生成
  - 工单：知识库问答系统（及格：检索准确率≥80%）

**软硬件工具**：LangChain、OpenAI API、向量数据库（Pinecone/Weaviate）

---

##### **模块M5：多智能体与强化学习（第11-12周，8课时）**

*难度标记：⭐⭐⭐⭐（高）*

**优化设计**：

- **第11周（4课时）**：多智能体设计基础
  
  - 智能体架构 → LLM驱动智能体 → 工具调用 → 多智能体通信
  - 工单：多智能体故障诊断系统（及格：协调正确率≥75%）

- **第12周（4课时）**：强化学习与系统集成
  
  - 强化学习基础（MDP、Q-Learning）→ 多智能体训练 → 综合项目答辩
  - 综合工单：工业生产多智能体调度系统

**软硬件工具**：Stable-Baselines3、Ray RLlib、LangChain多智能体框架

**第二部分：具体的数据集与工具**

1. **M1数据生成工具**：
   
   ```
   工具名称：industrial-data-generator
   功能：生成符合工业特征的传感器数据
   特性：可配置缺失率、异常率、噪声水平、时间戳格式
   输出格式：CSV / Parquet / JSON
   ```

2. **M2-M3图像数据集**：
   
   ```
   数据集：Industrial_Defect_Dataset_v2
   包含：1000+标注工业缺陷图像
   覆盖：焊缝、表面、螺钉、涂层等常见缺陷
   格式：COCO / YOLO格式标注
   ```

3. **M4知识库**：
   
   ```
   格式：向量数据库+检索索引
   内容：设备手册、故障案例库、维修指南
   大小：500+文档，向量维度：1536
   ```

4. **M5环境模拟器**：
   
   ```
   工具：gym-industrial-v1
   环境：虚拟生产线、多工序协调
   状态空间：6维（各工序产能、故障状态、能耗等）
   动作空间：离散（10个调度决策）
   ```

## 五、学习评价

### （一）课程评价

#### 1. **评价理念**（大一新生适配）

- **成长导向**：关注学生从"零基础"到"能独立完成项目"的成长过程
- **学生中心**：尊重个体差异，提供分层评价与反馈
- **形成性评价**：过程评价贯穿全程，及时反馈，适时调整
- **多维评价**：不仅考察知识与技能，更关注思维、创新、伦理

#### 2. **评价构成**

**过程性评价（80%）**：

- 出勤与课堂表现（10%）
- 课中实践与讨论（15%）
- 周工单任务（55%）

**期末评价（20%）**：

- 综合项目展示（15%）
- 系统答辩与反思（5%）

#### 3. **详细评分标准**

**出勤与课堂表现（10%，满分100分）**：

- 正常出勤：100分
- 缺勤1-2次：80分
- 缺勤3-4次：60分
- 缺勤≥5次：不合格

**课中实践（15%，满分100分）**：

- 代码能正确运行、参数理解正确：40分
- 积极参与讨论、提出问题或见解：30分
- 能独立分析与改进代码：30分

**周工单任务（55%，满分100分）** — **关键评估维度**

每个工单独立评分，采用"及格"与"优秀"两个等级：

| 评分项       | 及格（70分）    | 优秀（85分）     | 超优（95分）    |
| --------- | ---------- | ----------- | ---------- |
| **代码规范**  | PEP8符合≥80% | PEP8符合≥95%  | PEP8符合100% |
| **功能完整**  | 核心功能完成     | 全部功能完成+边界处理 | 功能完整+鲁棒性强  |
| **性能指标**  | 达到"及格标准"   | 达到"优秀标准"    | 超过"优秀标准"   |
| **文档与注释** | 主要逻辑有注释    | 全部代码有详细注释   | 包含使用说明+案例  |
| **创新应用**  | 不要求        | 有小的改进或扩展    | 有显著创意与价值   |

**示例**（以M2-1故障分类预测为例）：

- **及格标准**（70分）：F1≥0.70、代码能运行、有基本注释
- **优秀标准**（85分）：F1≥0.85、代码规范、文档完善、有一个改进亮点
- **超优**（95分）：F1≥0.90、代码规范、文档优秀、有多个创新点或显著工业应用价值

**期末综合项目答辩（20%，满分100分）**：

| 评分项    | 满分  | 标准                              |

| 技术深度   | 30分 | 至少融合2个高级技术（深度学习、大模型、多智能体等），理解深刻 |

## 24. nbgrader 原生作业系统 (v2.4 新增)

### 概述

JupyterHub 已安装 **nbgrader 0.9.5**，提供原生的作业分发、收集、自动评分和反馈功能，替代了之前的手动 code_grader.py。

### 教师操作流程

```bash
cd ~/work/nbgrader

# 1. 创建作业（在 source/ 目录下创建 Notebook）
#    在 JupyterLab 中使用 nbgrader 工具栏标记单元格类型:
#    - 答案区（Solution）: 学生需要填写的代码
#    - 测试区（Test）: assert 断言（自动评分用）
#    - 只读区（Read-only）: 题目描述

# 2. 生成学生版（自动去除解决方案）
python3 -m nbgrader generate_assignment ps1

# 3. 发布作业到 exchange
python3 -m nbgrader release_assignment ps1

# 4. 查看已发布的作业
python3 -m nbgrader list

# 5. 学生提交后，自动评分
python3 -m nbgrader autograde ps1

# 6. 生成反馈
python3 -m nbgrader generate_feedback ps1
python3 -m nbgrader release_feedback ps1

# 7. 导出成绩 CSV
python3 -m nbgrader export
```

### 学生操作流程

```bash
cd ~/work/nbgrader

# 1. 查看可用作业
python3 -m nbgrader list

# 2. 获取作业
python3 -m nbgrader fetch ps1

# 3. 完成作业后提交
python3 -m nbgrader submit ps1
```

### nbgrader 元数据要求

每个 nbgrader 单元格需要完整的 v3 元数据:
- `grade`: True/False（是否评分）
- `solution`: True/False（是否答案区）
- `task`: False
- `locked`: True/False（是否锁定）
- `points`: 浮点数（分值）
- `grade_id`: 唯一标识符
- `schema_version`: 3
- `cell_type`: "code"

### Exchange 目录

| 路径 | 说明 |
|------|------|
| `~/work/nbgrader/exchange/` | 共享交换目录 |
| `exchange/default/outbound/` | 教师发布的作业 |
| `exchange/default/inbound/` | 学生提交的作业 |
