《AI应用基础》是工业互联网应用专业的核心课程，面向专科一年级新生开设。本课程建立在《Python编程基础》基础之上，以工业实际应用为驱动，通过数据分析、特征工程、分类预测、时间序列预测、异常检测等AI技术，培养学生在工业互联网领域的数据驱动决策能力。

**课程定位**：
1. **职业面向**：适配工业互联网四大核心岗位的AI应用需求
2. **知识结构**：从数据处理基础逐步深化到预测维护与决策支持

## 二、教学目标

### （一）知识目标

1. **数据处理与分析基础**
   - 掌握Pandas数据处理、数据清洗、数据验证的方法
   - 理解数据统计、相关性分析、数据分布的概念
   - 了解特征工程的基本思想与常见技术

2. **机器学习基础**
   - 理解有监督学习与无监督学习的区别
   - 掌握分类模型的基本概念（决策树、随机森林、支持向量机）
   - 理解回归模型的原理与应用（线性回归、非线性回归）
   - 了解模型评估的指标体系（精确率、召回率、F1分数、ROC曲线等）

3. **时间序列与预测**
   - 理解时间序列的特征（趋势、季节性、波动）
   - 掌握经典时间序列模型（ARIMA、Prophet）
   - 了解深度学习时间序列模型的基本概念
   - 理解预测误差的评估方法（MAE、RMSE、MAPE）

4. **异常检测与预测维护**
   - 掌握基于统计的异常检测方法
   - 理解隔离森林（Isolation Forest）等无监督异常检测
   - 了解预测维护（Predictive Maintenance）的全流程
   - 理解RUL（残存寿命）预测的概念

5. **模型部署与实用性**
   - 理解模型选择与超参数调优的策略
   - 掌握模型持久化与加载（joblib、pickle）
   - 了解模型的可解释性与业务价值
   - 理解边缘计算环境下的模型轻量化需求

### （二）能力目标

1. **数据分析能力**
   - 能够进行完整的数据探索性分析（EDA）

   - 能够进行交叉验证与超参数调优
   - 能够处理类别不均衡问题

3. **时间序列预测能力**
   - 能够进行时间序列的平稳性检验
   - 能够训练ARIMA、Prophet等模型进行短期预测
   - 能够评估预测模型的准确性与可靠性
   - 能够处理多步长预测问题

4. **异常检测与故障预测能力**
   - 能够设计异常检测算法
   - 能够进行设备故障的早期预警
   - 能够估算设备的残存寿命（RUL）
   - 能够优化维护策略

5. **模型应用能力**
   - 能够将模型部署为可用的预测服务
   - 能够编写模型使用说明与预测结果解读
   - 能够进行A/B测试与模型效果验证
   - 能够应对模型退化（model drift）问题

## 三、教学内容

### （一）教学方式

#### 1. 理实一体教学
通过案例讲解算法原理，结合Jupyter Notebook/Python脚本演示代码实现，学生实时跟进修改参数、观察模型效果变化，形成"理解→编码→实验→优化"的闭环。

**实现方式**：
- 讲解阶段（15分钟）：讲解算法原理、超参数含义、应用场景
- 演示阶段（15分钟）：使用真实工业数据演示模型训练与评估
- 实践阶段（25分钟）：学生改变超参数、数据预处理方式，观察效果变化

**案例融合**：每堂课都围绕真实工业问题设计，例如：
- "分类模型" → 设备故障分类预测
- "时间序列" → 生产线产量预测
- "异常检测" → 传感器数据异常识别

#### 2. 项目驱动学习
将课程内容组织为若干个递进式、任务化的"AI工单项目"，每个工单都是完整的、可评估的、有业务价值的AI应用。

**工单特征**：
- 规模：200-500行代码 + Jupyter Notebook + 模型文件
- 产出：完整的.py模型库 + .ipynb探索记录 + 模型评估报告
- 场景：模拟真实的工业AI应用（预测、诊断、优化）
- 评价：按模型性能、代码规范、文档完整性评分

**工单层级**：
- L1（入门）：单个算法的直接应用与调参
- L2（进阶）：多个算法的对比与集成
- L3（挑战）：创新特征工程或新算法的探索

#### 3. 数据驱动的迭代学习
使用真实或仿真的工业数据集，让学生在数据探索、特征工程、模型训练、结果分析的过程中不断迭代改进。

**数据集支持**：
- 工业传感器采样数据（温度、压力、振动等）
- 设备故障历史数据（标记故障类型与发生时间）
- 生产线产量与质量数据
- 仿真数据生成脚本（OpenAI Gym、自定义生成器）

#### 4. 模型对标与评估
强调模型选择的科学性，通过实验对比不同算法在同一任务上的表现，帮助学生理解"没有最好的算法，只有最合适的算法"。

**对标方式**：
- 同一数据集上多个模型的性能对比
- 不同超参数下的性能曲线分析
- 模型复杂度与准确率的权衡

### （二）教学内容与进度

#### **模块M1：数据处理与特征工程（第1-4周，16课时）**

##### **任务M1.1：数据探索与清洗（第1-2周，8课时）**

**学习目标**：
- 知识：掌握Pandas数据操作、数据清洗、异常值检测方法
- 能力：能够进行完整的EDA分析；能够处理缺失值与异常值
- 素质：培养数据质量意识

**学习流程**：

1. **Pandas数据处理基础**（2课时）
   - DataFrame与Series的创建、索引、切片
   - 常用操作：groupby()、merge()、pivot_table()
   - 数据加载与存储（CSV、Excel、JSON）
   - 性能优化：数据类型选择、内存优化

2. **数据探索性分析（EDA）**（2课时）
   - 数据基本统计（均值、中位数、标准差、分布）
   - 缺失值分析与可视化
   - 异常值识别（3σ规则、IQR方法、可视化检测）
   - 相关性分析与特征关系探索

3. **数据清洗**（2课时）
   - 缺失值处理（删除、前向填充、均值填充、插值）
   - 异常值处理（删除、调整、鲁棒转换）
   - 重复数据处理
   - 数据类型转换与格式统一

4. **数据验证与质量评估**（2课时）
   - 数据验证规则的设计与执行
   - 完整性、准确性、一致性的检查
   - 数据质量评分机制
   - 工业数据质量特殊问题（传感器故障、时间不同步等）

**标准与规范**：
- Pandas官方文档与最佳实践
- 数据质量评估标准（ISO 8601、GB/T标准）

**软硬件工具**：
- Python Pandas、NumPy库
- Jupyter Notebook
- 数据可视化：Matplotlib、Seaborn

**教学设计**：
| 环节 | 知识目标 | 能力目标 | 素质目标 | 工具 | 教学方法 |
|------|--------|--------|--------|------|--------|
| Pandas基础 | 掌握DataFrame操作 | 能快速处理数据 | 效率意识 | Pandas | 对比演示 |
| EDA | 理解数据特征 | 能进行数据分析 | 深入思考 | Matplotlib | 案例驱动 |
| 清洗 | 掌握清洗方法 | 能处理脏数据 | 质量意识 | Pandas | 实操演练 |
| 验证 | 理解数据质量 | 能设计验证规则 | 工程思维 | Python | 综合应用 |

**典型案例**：
- 案例1："工业传感器数据清洗"，处理缺失、异常、不同步的多个传感器数据
- 案例2："设备故障历史数据分析"，发现故障类型分布、时间规律
- 案例3："生产质量数据关联分析"，找出影响产品质量的关键因素

**工单项目M1.1**：
- **项目名称**："工业设备采样数据清洗与分析"
- **需求描述**：给定1000+条设备采样数据（包含缺失值、异常值、重复数据），进行完整的清洗与EDA分析，生成数据质量评估报告
- **验收标准**：
  - 正确处理≥3种数据质量问题
  - 生成≥5个数据分布图表
  - 清洗后的数据质量评分≥80分
  - 代码规范率≥90%
  - 包含EDA分析报告（Markdown + 图表）

##### **任务M1.2：特征工程与特征选择（第3-4周，8课时）**

**学习目标**：
- 知识：掌握特征工程的思想与常见技术；理解特征选择的方法
- 能力：能够设计有效的特征；能够进行特征规范化与降维
- 素质：培养"特征工程的价值 > 模型选择"的意识

**学习流程**：

1. **特征构造与变换**（2课时）
   - 基础特征构造（多项式、交互特征、分组统计）
   - 时间特征提取（时间戳→小时、星期、季节等）
   - 数据规范化与标准化（Min-Max、Z-score、RobustScaler）
   - 特征编码（One-Hot、Label Encoding、Target Encoding）

2. **特征工程在工业中的应用**（2课时）
   - 传感器数据特征提取（均值、标准差、峰值、频率特征）
   - 滑动窗口特征（移动平均、指数加权）
   - 设备运行状态的特征标签化
   - 案例：从原始传感器数据到预测特征的转换

3. **特征选择与降维**（2课时）
   - 特征选择方法：过滤法、包装法、嵌入法
   - 相关性分析（皮尔逊、斯皮尔曼相关系数）
   - 特征重要性评估（树模型、排列重要性）
   - 主成分分析（PCA）与其他降维方法

4. **特征管道与自动化**（2课时）
   - sklearn Pipeline的设计与使用
   - 特征工程的可复用性与版本控制
   - 工业应用中的特征管理
   - 案例：完整的特征处理流程代码化

**标准与规范**：
- sklearn预处理模块文档
- 特征工程最佳实践

**软硬件工具**：
- Python scikit-learn、Pandas库
- 特征可视化工具

**教学设计**：
| 环节 | 知识目标 | 能力目标 | 素质目标 | 工具 | 教学方法 |
|------|--------|--------|--------|------|--------|
| 构造 | 掌握特征构造方法 | 能创意设计特征 | 创新思维 | Pandas | 案例对比 |
| 应用 | 理解工业场景 | 能提取领域特征 | 工业认知 | Python | 实操驱动 |
| 选择 | 掌握选择方法 | 能评估特征价值 | 分析能力 | scikit-learn | 实验对比 |
| 管道 | 理解工程化 | 能构建可复用流程 | 工程思维 | Pipeline | 最佳实践 |

**典型案例**：
- 案例1："设备故障预测特征工程"，从原始传感器数据构造20+个特征
- 案例2："时间序列特征提取"，滑动窗口生成序列特征
- 案例3："特征选择对比"，展示特征选择如何提升模型性能

**工单项目M1.2**：
- **项目名称**："工业设备预测特征库设计"
- **需求描述**：基于工业传感器原始数据，设计完整的特征工程流程，构造≥15个相关特征，进行特征选择与降维，最终输出用于预测建模的特征集
- **验收标准**：
  - 构造≥15个有意义的特征
  - 进行特征相关性分析与可视化
  - 使用≥2种特征选择方法

  - 包含特征工程设计文档

## 附录：常见问题与学习建议

### 常见建模问题解决流程
1. **问题现象**→**查看数据分布**→**检查特征工程**→**尝试不同模型**→**进行超参数调优**→**分析错误案例**→**查阅文献或咨询教师**

### 模型选择决策树
```
分类问题？
├─ 二分类 → 逻辑回归 / SVM / XGBoost
└─ 多分类 → 随机森林 / XGBoost / 神经网络

回归问题？
├─ 线性关系 → 线性回归 / Ridge
└─ 非线性关系 → 随机森林 / XGBoost / 多项式回归

时间序列？
├─ 短期预测（<50步） → ARIMA / Prophet
└─ 长期预测 → 机器学习 / 深度学习

异常检测？
├─ 单变量 → 3σ规则 / IQR
└─ 多变量 → 隔离森林 / 距离法
```

### 推荐学习资源链接
- Scikit-learn文档：https://scikit-learn.org/stable/documentation.html
- XGBoost文档：https://xgboost.readthedocs.io/
- Statsmodels：https://www.statsmodels.org/
- Facebook Prophet：https://facebook.github.io/prophet/
- Kaggle竞赛：https://www.kaggle.com/

### 学生成功案例建议
- 从简单问题开始（如二分类），逐步向复杂问题升级
- 重视EDA与特征工程，这往往比模型选择更重要
- 不要过度调参，在基准模型达到合理性能后再优化
- 定期进行模型诊断，理解预测失败的原因
- 记录学习日志，跟踪改进思路与实验结果

## 24. nbgrader 原生作业系统 (v2.4 新增)

### 概述

cd ~/work/nbgrader

# 7. 导出成绩 CSV
python3 -m nbgrader export

### nbgrader 元数据要求

- `grade`: True/False（是否评分）
- `solution`: True/False（是否答案区）
- `task`: False
- `locked`: True/False（是否锁定）
- `points`: 浮点数（分值）
- `grade_id`: 唯一标识符
- `schema_version`: 3
- `cell_type`: "code"
