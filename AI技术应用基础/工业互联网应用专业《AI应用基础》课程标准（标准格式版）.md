### （二）课程性质与定位

《AI应用基础》是工业互联网应用专业的**核心专业课程**，面向专科一年级新生设计。课程总学时48（理论24+实习24），总学分3分。

**课程定位**：
1. **知识基础**：系统讲授传统机器学习、深度学习、计算机视觉、自然语言处理、大模型与智能体等AI核心技术
2. **能力训练**：通过8个递进式工单项目+1个综合项目，培养学生在工业场景中应用AI的实践能力
3. **行业对接**：紧密对接工业互联网人才需求，以故障预测、缺陷检测、数据分析、智能决策为核心应用场景
4. **岗位支撑**：为工业数据采集技术员、边缘计算运维员、工业网络实施与运维工程师、工业互联网平台运维员四大岗位培养专业能力

### （三）课程基本教学理念

#### 1. **工程实践优于理论** 
以实际工业问题为驱动，先解决问题后理解理论。每个知识点都配有真实工业数据演示，学生通过改变超参数观察模型效果变化，建立深层理解。

#### 2. **融合多维AI技术路线**
- **传统ML**：快速、可解释、轻量化（适合边缘计算）
- **深度学习**：精度高、自动特征提取（适合复杂场景）
- **大模型与智能体**：多模态融合、自适应决策（适合综合系统）

#### 3. **零硬件与虚拟产线方案**
- 不依赖额外硬件（如树莓派、传感器等）
- 使用虚拟产线数据生成工具模拟真实工业场景
- 学生可在个人笔记本上完整学习全套AI应用流程

#### 4. **模型可解释性与可信AI**
- 强调模型结果的可解释性（特征重要性、决策路径）
- 关注模型的鲁棒性、公平性、隐私保护
- 培养学生的AI伦理意识

#### 5. **岗位能力递进培养**
- **初级能力**（第1-4周）：数据处理、基础建模
- **中级能力**（第5-8周）：深度学习、视觉应用
- **高级能力**（第9-12周）：大模型应用、智能体系统、系统集成

### （四）对接"1+X"证书

- **AI应用实践职业技能等级证书**（中国信息技术化教育认证）
- **工业互联网数据分析职业技能证书**
- **计算机视觉应用技能认证**

## 二、教学目标

### （一）知识目标

1. **掌握传统机器学习**
   - 理解监督学习与无监督学习的基本原理
   - 掌握分类、回归、聚类等常用算法
   - 理解模型评估指标（精确率、召回率、F1、MSE、R²等）

2. **掌握深度学习基础**
   - 理解神经网络的基本原理（激活函数、反向传播、梯度下降）
   - 掌握CNN、RNN、LSTM等深层网络结构及应用场景
   - 理解Transformer架构与注意力机制
   - 掌握大模型的基本原理与Prompt工程

3. **掌握计算机视觉技术**
   - 理解图像预处理、特征提取的方法
   - 掌握图像分类、物体检测、语义分割的基本原理
   - 理解迁移学习与多模态视觉大模型应用

4. **掌握自然语言处理**
   - 理解文本预处理、分词、词向量等基础技术
   - 掌握文本分类、情感分析的实现方法
   - 理解大模型（LLM）、Prompt工程、RAG系统

5. **掌握智能体与多智能体系统**
   - 理解智能体的架构与工作流程
   - 掌握LLM驱动的智能体设计
   - 理解多智能体通信、协调、冲突解决机制

## 三、教学内容

### （一）教学方式

#### 1. **理实一体教学**
通过案例讲解算法原理，结合Jupyter Notebook/Python脚本演示代码实现，学生实时跟进修改参数、观察模型效果变化，形成"理解→编码→实验→优化"的闭环。

**实现方式**：
- 讲解阶段（15分钟）：讲解算法原理、超参数含义、应用场景
- 演示阶段（15分钟）：使用真实工业数据演示模型训练与评估
- 实践阶段（25分钟）：学生改变超参数、数据预处理方式，观察效果变化

#### 2. **真实工业问题驱动**
每堂课都围绕真实工业问题设计，例如：
- "分类模型"→ 设备故障分类预测
- "时间序列"→ 生产线产量预测
- "异常检测"→ 传感器数据异常识别
- "缺陷检测"→ 产品质量检测
- "多智能体"→ 生产调度协调

#### 3. **工单项目制教学**
每个模块配置1-2个工单项目，每个项目包含：
- **任务描述**：明确的业务需求
- **评估标准**：具体的性能指标
- **实现框架**：代码框架与步骤指导
- **展示答辩**：学生演示与讲解项目

#### 4. **虚拟产线与仿真**
- 提供虚拟产线数据生成工具（无需额外硬件）
- 学生在仿真环境中完整体验AI应用流程
- 降低实践成本，提高学习效率

#### 5. **分层教学**
- **基础班**：强化数据处理与基础建模
- **提升班**：深入深度学习与大模型应用
- 按照学生程度提供差异化任务

#### 模块详细内容

##### **模块M1：数据处理与特征工程（第1-2周，8课时）**

**学习内容**：Pandas数据处理、EDA分析、特征工程、特征选择

**学习目标**：
- 知识：掌握数据清洗、探索性分析、特征工程的完整流程
- 能力：能够独立进行数据质量评估、特征设计与选择
- 素质：培养数据驱动的工程思维

**学习流程**：

**第一部分：数据清洗与质量评估（2课时）**
- 缺失值处理、异常值识别、重复值处理
- 数据质量指标体系
- 工业应用：传感器数据质量评估

**第二部分：探索性分析EDA（2课时）**
- 单变量分布分析、多变量相关性分析
- 时间序列趋势与季节性识别
- 数据可视化与洞察挖掘

**第三部分：特征工程设计（2课时）**
- 数值特征：缩放、分桶、交叉
- 文本特征：TF-IDF、Word2Vec
- 时间特征：周期、趋势、滞后特征

**第四部分：特征选择与工程优化（2课时）**
- 方差分析、相关性筛选、特征重要性评估
- 自动化特征选择工具
- 工业应用：最优特征组合选择

**软硬件工具**：Pandas、NumPy、Matplotlib、Seaborn、Scikit-learn

**工单项目M1**：
- 项目名称：工业设备采样数据清洗与质量评估系统
- 需求：完整的数据清洗与特征设计流程
- 验收标准：缺失值处理率≥95%、异常识别准确率≥90%、代码规范率≥90%

##### **模块M2：机器学习与深度学习（第3-6周，16课时）**

**学习内容**：分类模型、XGBoost、神经网络、CNN、RNN、LSTM、Transformer、大模型基础、LLM原理

**学习目标**：
- 知识：掌握传统ML到深度学习到大模型的完整路线
- 能力：能够独立构建与优化各类模型
- 素质：培养系统级的ML工程思维

**学习流程**：

**第一部分：监督学习与分类模型（3课时）**
- 逻辑回归、决策树、支持向量机（SVM）
- 模型评估指标：精确率、召回率、F1分数、AUC、混淆矩阵
- 工业应用案例：故障分类预测

**第二部分：集成学习与XGBoost（3课时）**
- 随机森林与梯度提升（GBDT）原理
- XGBoost的超参数调优
- 工业应用：多因素故障预测，性能提升

**第三部分：神经网络基础（2课时）**
- 感知机、多层神经网络（MLP）
- 激活函数、损失函数、优化器
- 反向传播与梯度下降

**第四部分：卷积神经网络CNN（2课时）**
- 卷积核、池化、全连接层
- 经典网络：AlexNet、ResNet、MobileNet
- 图像分类与特征提取

**第五部分：循环神经网络与LSTM（2课时）**
- RNN与梯度消失问题
- LSTM的门机制与状态管理
- 时间序列预测应用

**第六部分：Transformer与大模型基础（2课时）**
- 自注意力机制（Self-Attention）
- Transformer编码器与解码器
- 大模型（LLM）的基本原理与应用

**软硬件工具**：Scikit-learn、XGBoost、TensorFlow、PyTorch、Pandas

**工单项目M2**：
- 项目1（第3-4周）：工业故障分类预测系统（传统ML→XGBoost）
  - 需求：完整的分类模型管道
  - 验收标准：F1分数≥0.80、特征重要性可解释、代码规范≥90%
  
- 项目2（第5-6周）：深度学习模型与时间序列预测
  - 需求：使用LSTM或CNN进行时间序列预测
  - 验收标准：MSE≤0.05、代码规范≥90%

##### **模块M3：计算机视觉与多模态应用（第7-9周，12课时）**

**学习内容**：图像分类、物体检测、迁移学习、视觉大模型、多模态融合

**学习目标**：
- 知识：掌握图像处理、物体检测、多模态大模型
- 能力：能够进行工业图像检测与诊断
- 素质：培养工业视觉AI的应用思维

**学习流程**：

**第一部分：图像预处理与特征提取（1.5课时）**
- 图像颜色空间转换与数据增强
- 特征金字塔、多尺度特征提取
- 工业应用：缺陷图像预处理

**第二部分：图像分类与迁移学习（2.5课时）**
- 使用预训练模型（ResNet、MobileNet）
- 微调与迁移学习策略
- 工业应用：产品分类、设备状态识别

**第三部分：物体检测与缺陷定位（2课时）**
- 物体检测算法：YOLO、Faster R-CNN

## 24. nbgrader 原生作业系统 (v2.4 新增)

### 概述

JupyterHub 已安装 **nbgrader 0.9.5**，提供原生的作业分发、收集、自动评分和反馈功能，替代了之前的手动 code_grader.py。

### 教师操作流程

```bash
cd ~/work/nbgrader

# 1. 创建作业（在 source/ 目录下创建 Notebook）
#    在 JupyterLab 中使用 nbgrader 工具栏标记单元格类型:
#    - 答案区（Solution）: 学生需要填写的代码
#    - 测试区（Test）: assert 断言（自动评分用）
#    - 只读区（Read-only）: 题目描述

# 2. 生成学生版（自动去除解决方案）
python3 -m nbgrader generate_assignment ps1

# 3. 发布作业到 exchange
python3 -m nbgrader release_assignment ps1

# 4. 查看已发布的作业
python3 -m nbgrader list

# 5. 学生提交后，自动评分
python3 -m nbgrader autograde ps1

# 6. 生成反馈
python3 -m nbgrader generate_feedback ps1
python3 -m nbgrader release_feedback ps1

# 7. 导出成绩 CSV
python3 -m nbgrader export
```

### 学生操作流程

```bash
cd ~/work/nbgrader

# 1. 查看可用作业
python3 -m nbgrader list

# 2. 获取作业
python3 -m nbgrader fetch ps1

# 3. 完成作业后提交
python3 -m nbgrader submit ps1
```

### nbgrader 元数据要求

每个 nbgrader 单元格需要完整的 v3 元数据:
- `grade`: True/False（是否评分）
- `solution`: True/False（是否答案区）
- `task`: False
- `locked`: True/False（是否锁定）
- `points`: 浮点数（分值）
- `grade_id`: 唯一标识符
- `schema_version`: 3
- `cell_type`: "code"

### Exchange 目录

| 路径 | 说明 |
|------|------|
| `~/work/nbgrader/exchange/` | 共享交换目录 |
| `exchange/default/outbound/` | 教师发布的作业 |
| `exchange/default/inbound/` | 学生提交的作业 |
