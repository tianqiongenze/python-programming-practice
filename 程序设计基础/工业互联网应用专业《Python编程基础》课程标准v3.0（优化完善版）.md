### （三）课程性质与定位

《Python编程基础》是工业互联网应用专业的一门**核心基础课程**，旨在培养学生的Python编程能力，特别是面向对象编程思想、第三方库应用和工业数据处理能力。

**课程性质**：
- 理论与实践相结合的基础课程
- 工业应用导向的工程实践课程
- 为后续AI应用、网络编程等课程奠定基础

**课程定位**：
- 通过真实工业数据处理场景进行教学
- 强调项目驱动和动手实践
- 培养学生的工程化软件开发思想
- **特别强调**：适合零编程基础或基础薄弱的大一新生

### （四）课程基本教学理念

1. **项目驱动，真实场景**：围绕工业数据采集、处理、展示的完整任务链设计课程
2. **理实一体，融合教学**：课堂讲解与实训操作同步进行，理论在实践中验证
3. **循序渐进的方法论**：基础语法 → 函数与模块 → 面向对象 → 第三方库应用
4. **代码规范，工程思维**：重视PEP 8规范、注释文档、单元测试等工程实践
5. **分层教学，因材施教**：困难学生有补强，优秀学生有拓展
6. **及时反馈，循环改进**：每周反馈、中期诊断、末期复习

### （五）对接"1+X"证书

本课程与以下职业证书体系对接：

## 二、教学目标

### （一）知识目标

1. **Python语言基础**（第1-3周重点）
   - 掌握Python基本语法、数据类型、运算符和表达式
   - 理解控制流（if/for/while）的逻辑结构和应用场景
   - 熟悉函数的定义、调用、参数、返回值

2. **面向对象编程基础**（第4-5周重点）
   - 理解类、对象、属性、方法的基本概念
   - 掌握继承、多态、封装的基本原理
   - 理解面向对象设计在工业应用中的价值

3. **数据结构与处理**（第6-7周重点）
   - 理解列表、元组、字典、集合等容器的特性
   - 掌握字符串处理、正则表达式的基本用法
   - 了解JSON、CSV数据格式的解析与生成

4. **第三方库应用**（第8-10周重点）
   - 掌握jieba中文分词与关键词提取基础
   - 理解wordcloud词云可视化原理
   - 掌握Pillow图像基本操作与处理
   - 了解reportlab PDF报告的自动生成

5. **文件操作与数据持久化**（第6-10周贯穿）
   - 掌握文件I/O操作（读写、追加、二进制）
   - 理解数据验证、异常处理、数据清洗的概念
   - 了解数据统计与可视化的基本方法

6. **工业网络通信基础**（第11周重点）
   - 理解TCP/IP、HTTP、MQTT、Modbus等协议基础
   - 掌握Socket编程基本概念
   - 了解工业数据采集协议的报文结构

## 三、教学内容

### （一）教学方式

本课程采用**"讲演做"三段式 + 分层教学 + 及时反馈**的教学方法：

#### **讲演做三段式（50分钟课堂）**

1. **讲（15分钟）**：教师讲解知识点的基本原理与概念
   - 算法原理讲解
   - 工业应用背景介绍
   - 常见错误预防

2. **演（15分钟）**：教师进行实时代码演示
   - 代码框架展示
   - 参数调整演示
   - 结果分析讲解

3. **做（20分钟）**：学生进行操作练习
   - 学生独立修改代码
   - 进行小实验
   - 记录现象与思考

#### **分层教学**

- **A班（快速班）**：基础扎实的学生，加深难度、提供进阶项目
- **B班（常规班）**：大多数学生，按标准进度进行
- **C班（补强班）**：基础薄弱的学生，提供基础补强、降低难度

#### **及时反馈**

- 每周反馈：工单完成后24小时内反馈成绩与改进意见
- 中期诊断：第6周进行进度检查，识别困难学生
- 补强计划：为落后学生制订个性化改进计划

## 24. nbgrader 原生作业系统 (v2.4 新增)

### 概述

JupyterHub 已安装 **nbgrader 0.9.5**，提供原生的作业分发、收集、自动评分和反馈功能，替代了之前的手动 code_grader.py。

### 教师操作流程

```bash
cd ~/work/nbgrader

# 1. 创建作业（在 source/ 目录下创建 Notebook）
#    在 JupyterLab 中使用 nbgrader 工具栏标记单元格类型:
#    - 答案区（Solution）: 学生需要填写的代码
#    - 测试区（Test）: assert 断言（自动评分用）
#    - 只读区（Read-only）: 题目描述

# 2. 生成学生版（自动去除解决方案）
python3 -m nbgrader generate_assignment ps1

# 3. 发布作业到 exchange
python3 -m nbgrader release_assignment ps1

# 4. 查看已发布的作业
python3 -m nbgrader list

# 5. 学生提交后，自动评分
python3 -m nbgrader autograde ps1

# 6. 生成反馈
python3 -m nbgrader generate_feedback ps1
python3 -m nbgrader release_feedback ps1

# 7. 导出成绩 CSV
python3 -m nbgrader export
```

### 学生操作流程

```bash
cd ~/work/nbgrader

# 1. 查看可用作业
python3 -m nbgrader list

# 2. 获取作业
python3 -m nbgrader fetch ps1

# 3. 完成作业后提交
python3 -m nbgrader submit ps1
```

### nbgrader 元数据要求

每个 nbgrader 单元格需要完整的 v3 元数据:
- `grade`: True/False（是否评分）
- `solution`: True/False（是否答案区）
- `task`: False
- `locked`: True/False（是否锁定）
- `points`: 浮点数（分值）
- `grade_id`: 唯一标识符
- `schema_version`: 3
- `cell_type`: "code"

### Exchange 目录

| 路径 | 说明 |
|------|------|
| `~/work/nbgrader/exchange/` | 共享交换目录 |
| `exchange/default/outbound/` | 教师发布的作业 |
| `exchange/default/inbound/` | 学生提交的作业 |
