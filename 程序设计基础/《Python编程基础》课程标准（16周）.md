### （二）课程性质与定位

本课程为对接工业互联网产业发展需求、适应高职教育改革，贯彻以培养高职学生实践技能为重点、基础理论与实际应用相结合的指导思想，力求体现精炼与实用。Python编程基础课程是工业互联网应用专业中具有重要应用价值的一门专业基础课程。其内容涵盖Python编程基础、数据结构、工业场景仿真、网络通信原理、机器学习与预测维护等核心模块，实践性突出。

本课程既要求学生掌握Python编程基础理论与软件操作原理，也强调结合**工业数据处理、故障诊断、设备预测维护**等工业互联网领域实际应用需求，提升学生的编程实践应用能力与工业AI思维。在教学过程中，应依据工业互联网应用专业学生的知识基础与**工业互联网数据处理、智能制造系统开发、设备预测维护**等岗位实际需求，合理组织教学内容。

采用适宜的教学方法，实现教、学、练一体化，注重理论知识与编程实践的融合，构建"在学习中开展编程与建模实践、在实践中深化编程与算法知识学习、以虚拟工业数据管道+故障预测项目为驱动"的教学模式，从而提升学生编程规范执行、工业数据处理及**数据驱动决策**能力。进一步提升学生综合素质（包括代码规范意识、编程思维、工业AI应用思维及与工业互联网技术融合的能力），增强其适应工业互联网领域Python编程与工业AI发展及岗位需求变化的能力，为后续工业互联网相关专业课程学习及职业发展奠定专业基础。

### （三）课程基本教学理念

**1. 工学结合与工业AI融合：** 课程结构以企业实际数据处理+**工业AI应用**需求为核心逻辑，深度对接行业岗位的**数据采集、清洗、分析、建模、预测**全流程场景。通过设计真实项目化学习模块（如虚拟产线数据采集项目、班次OEE分析项目、**设备故障预测项目**等），让学生在完成具体数据处理与**AI应用**任务的过程中，将编程理论知识与Python工具、**机器学习算法**有机融合，系统提升学生的数据处理能力、**工业AI应用能力**及岗位适配的编程实操能力。

**2. 理论与实践相融：** 坚持"理论为实践奠基、实践为理论赋能"的原则，在理论教学中嵌入实践案例（如变量类型结合传感器数据、条件分支结合故障诊断、网络通信结合工业协议MQTT、**机器学习结合设备故障预测**等），在实践教学中强化理论支撑。通过"理论讲解→应用案例→代码实现→结果验证"的闭环教学流程，确保每个学生都能将所学编程与**建模**理论知识应用于实际**工业数据处理与预测维护**，在实操中检验代码的正确性、**模型的有效性**，深化对编程与**算法**概念的理解。

**3. 自主学习：** 以"激发兴趣、引导探索"为导向，通过设置开放性问题（如"如何快速处理100万条传感器数据？""如何预测设备何时会故障？"）、提供个性化学习资源（如Python官方文档、Scikit-learn教程、开源项目代码库、**工业预测维护案例集**），鼓励学生主动探索编程与**机器学习**新知。在项目实施过程中，教师从"主导者"转变为"引导者"，只提供关键编程思路、**建模思路**和资源支持，让学生**独立完成特征工程、模型训练、结果评估**等环节，逐步培养其独立思考能力、自我解决编程+建模问题能力及**创新AI应用思维**。

**4. 网络课程深度协同：** 本课程与《计算机网络基础》同步进行，形成"互补螺旋"式学习路径。在第1-16周，Python课程与网络课程深度联动，实现"一个变量=一个数据包""一个函数=一次网络通信""一个JSON数据=网络报文"的类比学习。通过设立**联合讲座（每2周一次60分钟）**和**联合答辩（第16周）**，使学生深刻理解编程与网络通信的融合，为工业互联网技术的学习奠定坚实基础。

**5. 仿真驱动的零硬件方案：** 采用创新的"软件仿真工业场景"方案，设计**三大仿真库**（工业数据仿真库、网络通信仿真库、工业KPI计算库），让学生在无需任何硬件设备的条件下，完整学习工业数据流从采集→传输→处理→分析→**预测决策**的全链路。通过虚拟产线系统仿真，学生可以体验真实工业场景，同时大幅降低教学成本，实现教学资源的最优配置。

**6. 赛证课企融合提升专业能力：** 以工学结合、能力递进为核心思路设计学习情境，课程从工业领域的编程与**数据分析应用**需求出发，遵循"基于工作过程、阶段性梯次递进"的原则，按照"基础编程—数据处理—系统集成—工业AI应用"的由简到难逻辑搭建内容框架。通过"教师引导—学生自主探究—小组协作完成"的模式，让学生在完成编程任务或**AI建模**项目的过程中，逐步实现对编程与**工业数据分析**工作流程的完整认识。同时，引导和辅助学生参与职业技能竞赛、考取职业资格证书（如"Python开发者认证证书"、"数据分析工程师证书"）等实践活动，将课堂学习与竞赛、考证有机融合，以赛促学、以证验学。

**7. 专业与素养结合提升应用能力：** 通过基础理论（如编程标准、数据结构、网络协议、**特征工程、模型训练**等）的系统学习，强化学生的理论功底，培养其综合分析**数据与模型问题**（如"分析模型预测错误的原因"）、应用理论解决实际**工业AI问题**（如"设计符合标准的故障预测系统"）的能力。同时，将编程安全规范教育（如"数据安全""隐私保护"）、职业素养培养（如"严谨的编程态度""团队协作意识"）、**工业AI伦理教育**（如"模型偏差、算法公正性"）、家国情怀熏陶（如"介绍我国工业互联网标准化进程"）融入课程教学全过程，实现专业能力与综合素质的协同提升。

## 二、教学目标

### （一）知识目标

1. **掌握Python编程基础：** 理解变量、数据类型、控制流（条件分支、循环）、函数、模块等核心编程概念。

2. **理解数据结构与序列化：** 掌握列表、字典、元组、集合等Python数据结构，理解JSON、CSV等数据序列化在网络通信与数据处理中的作用。

3. **认知网络通信基础：** 结合网络课程，理解TCP/UDP、HTTP、MQTT等协议原理，理解网络基础概念与编程语言的关联。

4. **掌握工业数据处理技能：** 理解文件I/O操作原理，掌握Pandas库进行数据清洗与分析，学会处理工业场景中的**时间序列数据、异常数据、缺失数据**。

5. **理解工业KPI计算：** 掌握OEE（设备综合效率）、MTBF等工业关键指标的计算原理与应用。

6. **【融合】理解机器学习与预测维护基础：**
   
   - 理解**监督学习、无监督学习**的基本原理
   - 掌握**特征工程**（特征提取、特征选择、特征缩放）的重要性
   - 理解**故障诊断、异常检测、剩余使用寿命（RUL）预测**等工业AI应用
   - 掌握**模型评估指标**（准确率、精准率、召回率、F1分数、混淆矩阵）
   - 理解**ISO 13373故障诊断标准、IEC 61670预测维护标准**的基本要求

### （二）能力目标

1. **独立编写程序的能力：** 能编写50行以上的完整Python脚本，掌握代码调试与异常处理。

2. **数据处理与分析能力：** 能用Pandas进行数据清洗、转换、聚合与分析，能用Pyecharts进行数据可视化。

3. **工业场景应用能力：** 能模拟传感器数据采集，能设计网络通信流程，能完成"虚拟产线数据管道"开发。

4. **工程思维与问题解决能力：** 能分析复杂工业问题，能设计合理的编程方案。

5. **自主学习与创新能力：** 能查阅官方文档自学新技术，能参与编程竞赛与考证。

6. **【融合】机器学习模型应用能力：**
   
   - 能用Scikit-learn进行**数据预处理、特征工程、模型训练**
   - 能进行**模型选择、参数调优、交叉验证**
   - 能用Prophet进行**时间序列预测与异常检测**
   - 能设计**故障预测系统**（输入原始数据→输出预测结果）
   - 能对模型进行**评估、验证、优化**
   - 能将**机器学习模型集成**到实际工业系统中

### （三）素质目标

**1. 编程规范意识与严谨态度：**

在日常学习与编程实践中养成严谨的代码编写习惯，遵循PEP8代码规范，强调"代码不仅要能运行，更要易于被他人理解与维护"的职业素养。培养对编程错误的敏感性，能够细致地进行代码审查与测试。

**2. 数据安全与伦理意识：**

培养对**工业数据安全、隐私保护**的重视，理解工业数据的敏感性与价值。了解机器学习模型可能存在的**偏差、不公正**等伦理问题，树立负责任的AI应用理念。理解"模型即代码"的理念，学会对模型的决策进行**可解释性分析**。

**3. 团队协作与沟通能力：**

在小组项目中主动承担适当的分工任务，能积极参与代码评审，学会清晰地向队友讲解自己的编程思路和**建模思想**。能虚心接纳他人的改进建议，形成互相支持、共同进步的团队文化。

**4. 工业数据驱动决策意识：**

通过虚拟产线、**故障预测**项目等教学设计，帮助学生理解**"数据驱动"**在工业互联网中的关键作用。树立"数据是工业互联网的血液，算法是工业互联网的大脑"的认识，培养对**证据驱动、科学决策**的理解。

**5. 大国工匠精神与创新意识：**

将马克思主义的实践观、发展观融入教学。例如在讲解"OEE计算"时强调"量变引起质变"的辩证关系，在讲解"**故障预测**"时阐述"实践是检验真理的唯一标准"。介绍我国**工业互联网标准化进程**中的成就，特别是**工业AI、预测维护**等领域的创新。激励学生追求卓越、精益求精，树立为国家制造业升级做贡献的远大志向。

### （四）研究与创新

### （五）可持续发展

**3. 可持续能力发展路径：**

## 三、教学内容

### （一）教学方式

**1. 理实一体教学：** 通过课堂讲解基础知识，结合实际工业案例讨论。

课堂中讲解Python编程基础与网络通信原理（包括变量类型、数据结构、网络协议等），结合工业或民用数据处理实际案例，组织学生研讨理论在代码中的应用场景、解决思路及方案可行性。**在进阶模块中，结合真实的设备故障案例、工业数据集，讲解特征工程、模型训练、预测等步骤**，实现理论与实践融合，帮助学生掌握编程规范并建立"理论指导编程、实践反哺理论"的专业思维。

**2. 仿真驱动学习：** 利用软件仿真工具模拟工业场景，增强学生对编程应用的理解。

        self.all_data = []
        self.fault_model = None  # 故障预测模型

    def simulate_24_hours(self):

        pass

    def step2_feature_engineering(self, df):
        """【新增】特征工程"""
        # 提取时间序列特征
        df['temp_diff'] = df.groupby('line_id')['temp_0'].diff()
        df['temp_mean'] = df.groupby('line_id')['temp_0'].rolling(10).mean().values
        df['vibration_std'] = df.groupby('line_id')['vibration_0'].rolling(10).std().values
        return df

    def step3_fault_prediction(self, df):
        """【新增】故障预测"""
        # 使用Scikit-learn训练简单的分类模型
        from sklearn.ensemble import RandomForestClassifier

        features = ['temp_0', 'temp_diff', 'temp_mean', 'vibration_std']
        X = df[features].dropna()

        # 假设df中有'fault_label'标签
        y = df.loc[X.index, 'fault_label']

        # 训练模型
        self.fault_model = RandomForestClassifier(n_estimators=10)
        self.fault_model.fit(X, y)

        # 预测
        df['fault_pred'] = self.fault_model.predict(X)
        return df

    def generate_report(self):
        """生成包含模型性能的报告"""
        from sklearn.metrics import f1_score, precision_score

        report = {
            'model_f1_score': f1_score(df['fault_label'], df['fault_pred'], average='weighted'),
            'model_precision': precision_score(df['fault_label'], df['fault_pred'], average='weighted'),
            'fault_predictions': df['fault_pred'].value_counts().to_dict()
        }
        return report

## 24. nbgrader 原生作业系统 (v2.4 新增)

### 概述

JupyterHub 已安装 **nbgrader 0.9.5**，提供原生的作业分发、收集、自动评分和反馈功能，替代了之前的手动 code_grader.py。

### 教师操作流程

```bash
cd ~/work/nbgrader

# 1. 创建作业（在 source/ 目录下创建 Notebook）
#    在 JupyterLab 中使用 nbgrader 工具栏标记单元格类型:
#    - 答案区（Solution）: 学生需要填写的代码
#    - 测试区（Test）: assert 断言（自动评分用）
#    - 只读区（Read-only）: 题目描述

# 2. 生成学生版（自动去除解决方案）
python3 -m nbgrader generate_assignment ps1

# 3. 发布作业到 exchange
python3 -m nbgrader release_assignment ps1

# 4. 查看已发布的作业
python3 -m nbgrader list

# 5. 学生提交后，自动评分
python3 -m nbgrader autograde ps1

# 6. 生成反馈
python3 -m nbgrader generate_feedback ps1
python3 -m nbgrader release_feedback ps1

# 7. 导出成绩 CSV
python3 -m nbgrader export
```

### 学生操作流程

```bash
cd ~/work/nbgrader

# 1. 查看可用作业
python3 -m nbgrader list

# 2. 获取作业
python3 -m nbgrader fetch ps1

# 3. 完成作业后提交
python3 -m nbgrader submit ps1
```

### nbgrader 元数据要求

每个 nbgrader 单元格需要完整的 v3 元数据:
- `grade`: True/False（是否评分）
- `solution`: True/False（是否答案区）
- `task`: False
- `locked`: True/False（是否锁定）
- `points`: 浮点数（分值）
- `grade_id`: 唯一标识符
- `schema_version`: 3
- `cell_type`: "code"

### Exchange 目录

| 路径 | 说明 |
|------|------|
| `~/work/nbgrader/exchange/` | 共享交换目录 |
| `exchange/default/outbound/` | 教师发布的作业 |
| `exchange/default/inbound/` | 学生提交的作业 |
