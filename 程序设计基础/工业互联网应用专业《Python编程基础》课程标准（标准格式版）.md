### （三）课程性质与定位

《Python编程基础》是工业互联网应用专业的一门**核心基础课程**，旨在培养学生的Python编程能力，特别是面向对象编程思想、第三方库应用和工业数据处理能力。

**课程性质**：
- 理论与实践相结合的基础课程
- 工业应用导向的工程实践课程
- 为后续AI应用、网络编程等课程奠定基础

**课程定位**：
- 通过真实工业数据处理场景进行教学
- 强调项目驱动和动手实践
- 培养学生的工程化软件开发思想

### （四）课程基本教学理念

1. **项目驱动，真实场景**：围绕工业数据采集、处理、展示的完整任务链设计课程
2. **理实一体，融合教学**：课堂讲解与实训操作同步进行，理论在实践中验证
3. **循序渐进的方法论**：基础语法 → 函数与模块 → 面向对象 → 第三方库应用
4. **代码规范，工程思维**：重视PEP 8规范、注释文档、单元测试等工程实践
5. **协同创新，开放评价**：学生自主探索、小组协作、多维度评价

### （五）对接"1+X"证书

本课程与以下职业证书体系对接：
- **Python开发职业技能等级证书**（工信部）
- **AI应用实践职业技能等级证书**（工业互联网平台运维方向）
- **企业应用实施工程师证书**

## 二、教学目标

### （一）知识目标

1. **Python语言基础**
   - 掌握Python基本语法、数据类型、运算符和表达式
   - 理解控制流（if/for/while）的逻辑结构和应用场景
   - 熟悉函数的定义、调用、参数、返回值

2. **面向对象编程基础**
   - 理解类、对象、属性、方法的基本概念
   - 掌握继承、多态、封装的基本原理
   - 理解面向对象设计在工业应用中的价值

3. **数据结构与处理**
   - 理解列表、元组、字典、集合等容器的特性
   - 掌握字符串处理、正则表达式的基本用法
   - 了解JSON、CSV数据格式的解析与生成

4. **第三方库应用**
   - 掌握jieba中文分词与关键词提取基础
   - 理解wordcloud词云可视化原理
   - 掌握Pillow图像基本操作与处理
   - 了解reportlab PDF报告的自动生成

5. **文件操作与数据持久化**
   - 掌握文件I/O操作（读写、追加、二进制）
   - 理解数据验证、异常处理、数据清洗的概念
   - 了解数据统计与可视化的基本方法

6. **工业网络通信基础**
   - 理解TCP/IP、HTTP、MQTT、Modbus等协议基础
   - 掌握Socket编程基本概念
   - 了解工业数据采集协议的报文结构

## 三、教学内容

### （一）教学方式

本课程采用**"讲演做"三段式教学方法**：

1. **讲（15分钟）**：教师讲解知识点的基本原理与概念
   - 算法原理讲解
   - 工业应用背景介绍
   - 常见错误预防

2. **演（15分钟）**：教师进行实时代码演示
   - 代码框架展示
   - 参数调整演示
   - 结果分析讲解

3. **做（20分钟）**：学生进行操作练习
   - 学生独立修改代码
   - 进行工单实验
   - 记录现象与思考

### （二）教学任务与工作内容

#### **模块0：Python编程基础与面向对象（第1-6周，24课时）**

##### 任务0.1：Python基础与数据类型（第1周，4课时）

**学习内容**：
- Python开发环境搭建与IDE配置
- Python基本语法、变量、数据类型
- 基本数据类型与运算
- 工业应用场景：设备参数初始化

**学习目标**：
- 知识：掌握Python基础语法、数据类型和基本操作
- 能力：能够编写50-100行的Python程序
- 素质：培养对编程工具的理解与应用

**工单项目0.1**：
- **项目名称**：设备参数初始化系统
- **需求描述**：建立工业设备的参数集合，使用不同数据类型存储设备ID、名称、工作状态、温度等信息
- **验收标准**：
  - 正确定义≥6个变量，涵盖不同数据类型
  - 正确计算设备的基本指标（如功率消耗）
  - 代码规范率≥90%

##### 任务0.2：控制流与函数（第2-3周，8课时）

**学习内容**：
- 条件判断（if/elif/else）
- 循环结构（for/while）
- 函数的定义、参数与返回值
- 工业应用场景：告警系统、循环采集

**学习目标**：
- 知识：掌握控制流逻辑与函数设计
- 能力：能够编写150-300行的程序，实现复杂逻辑
- 素质：培养逻辑思维与模块化思想

**工单项目0.2**：
- **项目名称**：工业实时告警系统
- **需求描述**：模拟设备的实时监测，当设备温度超过阈值、压力异常时触发多级告警。系统需要根据告警级别采取不同的响应措施
- **验收标准**：
  - 设计≥3个告警等级
  - 实现多条件判断与嵌套逻辑
  - 能够正确输出告警信息与建议

##### 任务0.3：面向对象编程（第4-5周，8课时）

**学习内容**：
- 类与对象的概念

- 知识：理解类、继承、多态、封装的基本概念

**工单项目0.3**：

- **需求描述**：设计一个通用的设备基类，包含属性（ID、名称、状态）和方法（启动、停止、诊断）。创建至少3个具体的设备子类（如PLC、变频器、传感器），实现继承和方法覆盖，演示多态特性
- **验收标准**：
  - 设计≥1个基类+3个子类
  - 实现继承与方法覆盖
  - 演示多态调用
  - 代码规范率≥90%
  - 包含docstring与注释

  - 包含try/except/finally完整结构

## 24. nbgrader 原生作业系统 (v2.4 新增)

### 概述

JupyterHub 已安装 **nbgrader 0.9.5**，提供原生的作业分发、收集、自动评分和反馈功能，替代了之前的手动 code_grader.py。

### 教师操作流程

```bash
cd ~/work/nbgrader

# 1. 创建作业（在 source/ 目录下创建 Notebook）
#    在 JupyterLab 中使用 nbgrader 工具栏标记单元格类型:
#    - 答案区（Solution）: 学生需要填写的代码
#    - 测试区（Test）: assert 断言（自动评分用）
#    - 只读区（Read-only）: 题目描述

# 2. 生成学生版（自动去除解决方案）
python3 -m nbgrader generate_assignment ps1

# 3. 发布作业到 exchange
python3 -m nbgrader release_assignment ps1

# 4. 查看已发布的作业
python3 -m nbgrader list

# 5. 学生提交后，自动评分
python3 -m nbgrader autograde ps1

# 6. 生成反馈
python3 -m nbgrader generate_feedback ps1
python3 -m nbgrader release_feedback ps1

# 7. 导出成绩 CSV
python3 -m nbgrader export
```

### 学生操作流程

```bash
cd ~/work/nbgrader

# 1. 查看可用作业
python3 -m nbgrader list

# 2. 获取作业
python3 -m nbgrader fetch ps1

# 3. 完成作业后提交
python3 -m nbgrader submit ps1
```

### nbgrader 元数据要求

每个 nbgrader 单元格需要完整的 v3 元数据:
- `grade`: True/False（是否评分）
- `solution`: True/False（是否答案区）
- `task`: False
- `locked`: True/False（是否锁定）
- `points`: 浮点数（分值）
- `grade_id`: 唯一标识符
- `schema_version`: 3
- `cell_type`: "code"

### Exchange 目录

| 路径 | 说明 |
|------|------|
| `~/work/nbgrader/exchange/` | 共享交换目录 |
| `exchange/default/outbound/` | 教师发布的作业 |
| `exchange/default/inbound/` | 学生提交的作业 |
