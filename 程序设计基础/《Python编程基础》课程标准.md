### （三）课程性质与定位

本课程为对接工业互联网产业发展需求、适应高职教育改革，贯彻以培养高职学生实践技能为重点、基础理论与实际应用相结合的指导思想，力求体现精炼与实用。Python编程基础课程是工业互联网应用专业中具有重要应用价值的一门专业基础课程。其内容涵盖Python编程基础、数据结构、工业场景仿真、网络通信原理等核心模块，实践性突出，既要求学生掌握Python编程基础理论与软件操作原理，也强调结合工业互联网领域工程实际，提升学生的编程实践应用能力。

在教学过程中，应依据工业互联网应用专业学生的知识基础与工业互联网数据处理、智能制造系统开发等岗位实际需求，合理组织教学内容，以培养学生工业互联网场景下Python编程与数据处理的职业能力及工匠精神为核心目标。同时采用适宜的教学方法，实现教、学、练一体化，注重理论知识与编程实践的融合，构建"**在学习中开展编程实践、在实践中深化编程知识学习、以虚拟工业数据管道项目为驱动**"的教学模式，从而提升学生编程规范执行、工业数据处理及工业互联网场景下数据管道设计与实现能力。进一步提升学生综合素质（包括代码规范意识、编程思维培养及与工业互联网技术融合的能力），增强其适应工业互联网领域Python编程与数据分析发展及岗位需求变化的能力，为后续工业互联网相关专业课程学习及职业发展奠定专业基础。

### （四）课程基本教学理念

**1. 工学结合：** 课程结构以企业实际数据处理需求为核心逻辑，深度对接行业岗位的数据采集、清洗、计算、展示场景，通过设计真实项目化学习模块（如虚拟产线数据采集项目、KPI计算与分析项目、工业互联网仪表板设计项目等），让学生在完成具体数据处理任务的过程中，将编程理论知识与Python工具操作有机融合，系统提升学生的数据处理能力、代码编写规范度及岗位适配的编程实操能力。

**2. 理论与实践相融：** 坚持"理论为实践奠基、实践为理论赋能"的原则，在理论教学中嵌入实践案例（如变量类型结合传感器数据、条件分支结合故障诊断、网络通信结合工业协议MQTT等），在实践教学中强化理论支撑，通过"理论讲解→应用案例→代码实现→结果验证"的闭环教学流程，确保每个学生都能将所学编程理论知识应用于实际数据处理，在实操中检验代码的正确性、深化对编程概念的理解，实现"知其然且知其所以然"的学习目标。

**3. 自主学习：** 以"激发兴趣、引导探索"为导向，通过设置开放性问题（如"如何快速处理100万条传感器数据？"）、提供个性化学习资源（如Python官方文档、开源项目代码库、工业应用案例集），鼓励学生主动探索编程新知；在项目实施过程中，教师从"主导者"转变为"引导者"，只提供关键编程思路和资源支持，让学生独立完成代码设计、调试验证、结果总结等环节，逐步培养其独立思考能力、自我解决编程问题能力及创新编程思维。

**4. 网络课程深度协同：** 本课程与《计算机网络基础》同步进行，形成"互补螺旋"式学习路径。在第1-16周，Python课程与网络课程深度联动，实现"一个变量=一个数据包""一个函数=一次网络通信""一个JSON数据=网络报文"的类比学习。通过设立联合讲座（每2周一次60分钟）和联合答辩（第16周），使学生深刻理解编程与网络通信的融合，为工业互联网技术的学习奠定坚实基础。

**5. 仿真驱动的零硬件方案：** 采用创新的"软件仿真工业场景"方案，设计三大仿真库（工业数据仿真库、网络通信仿真库、工业KPI计算库），让学生在无需任何硬件设备的条件下，完整学习工业数据流从采集→传输→处理→展示的全链路。通过虚拟产线系统仿真，学生可以体验真实工业场景，同时大幅降低教学成本，实现教学资源的最优配置。

**6. 分层教学与递进深化：** 采用ABC三层分层教学策略，根据学生的学习进度与能力水平，提供不同难度的学习任务。C层（学习困难）：运行现成代码，理解逻辑；B层（正常学习）：修改模板，完成标准任务；A层（快速学习）：独立编写，探索扩展。每个工单都有三个层级的学习路径，确保"没有学不会的学生，只有教不好的老师"。

## 二、教学目标

### （一）知识目标

1. **掌握Python编程基础：** 理解变量、数据类型、控制流（条件分支、循环）、函数、模块等核心编程概念，理解编程语言的逻辑思维方式。

2. **理解数据结构原理：** 掌握列表、字典、元组、集合等Python数据结构的应用场景与操作方法，理解数据序列化（JSON、CSV）在网络通信中的作用。

3. **认知网络通信基础：** 结合网络课程，理解TCP/UDP、HTTP、MQTT等协议原理，理解IP地址、端口、报文格式等网络基础概念与编程语言的关联。

4. **掌握数据处理技能：** 理解文件I/O操作原理，掌握Pandas库进行数据清洗与分析，学会用Python处理工业场景中的时间序列数据。

5. **理解工业KPI计算：** 掌握OEE（设备综合效率）、MTBF（平均故障间隔）等工业关键指标的计算原理，理解业界标准与工业应用意义。

### （二）能力目标

1. **独立编写程序的能力：** 能编写50行以上的完整Python脚本，能独立解决日常编程问题，掌握代码调试与异常处理方法。

2. **数据处理与分析能力：** 能用Pandas库对工业数据进行清洗、转换、聚合与分析，能用Pyecharts进行数据可视化，能生成工业KPI报告。

3. **工业场景应用能力：** 能模拟传感器数据采集，能理解与设计网络通信流程，能完成"虚拟产线数据管道"的从0到1开发。

4. **工程思维与问题解决能力：** 能分析复杂工业问题，能设计合理的编程方案，能用代码表达与验证工程概念。

5. **自主学习与创新能力：** 能查阅官方文档自学新的Python库与技术，能对学习内容进行拓展与创新，能参与编程竞赛与考证。

### （三）素质目标

**1. 编程规范意识与严谨态度：**

在日常学习与编程实践中养成严谨的代码编写习惯，遵循PEP8代码规范（如标准的缩进、命名规则、注释规范），强调"代码不仅要能运行，更要易于被他人理解与维护"的职业素养。培养对编程错误的敏感性，能够细致地进行代码审查与测试，形成"严谨编程、安全第一"的职业精神。

**2. 团队协作与沟通能力：**

在小组项目中主动承担适当的分工任务，能积极参与代码评审（code review），学会清晰地向队友讲解自己的编程思路，能虚心接纳他人的改进建议，形成互相支持、共同进步的团队文化。培养跨专业沟通能力，能与网络课程的学生、产业实践的工程师进行有效的技术交流。

**3. 工业数据安全与法规意识：**

培养对数据安全、隐私保护的重视，理解工业数据的敏感性与价值，遵守数据存储与传输的安全规范。了解软件知识产权、开源协议等法律问题，树立尊重他人劳动成果、合法使用开源代码的法律意识。

**4. 工业互联网融合意识：**

通过虚拟产线、网络协同等教学设计，帮助学生理解编程技术在工业互联网中的关键作用，树立"编程是工业互联网的基石"的认识，培养对工业技术发展的关注与思考。

**5. 大国工匠精神与创新意识：**

将马克思主义的实践观、发展观融入教学，例如在讲解"OEE计算"时强调"量变引起质变"的辩证关系，介绍我国工业互联网标准化进程中的成就。激励学生追求卓越、精益求精，鼓励技术创新，树立为国家制造业升级做贡献的远大志向。

### （四）研究与创新

**1. 创新教学内容与手段：**

- 首创"虚拟工业场景仿真"教学模块，设计三大仿真库（工业数据仿真库、网络通信仿真库、工业KPI计算库），使学生在零硬件条件下完整体验工业数据流。
- 新增"网络课程协同"设计，形成Python与网络课程的"互补螺旋"式学习路径，使学生深刻理解编程与网络通信的融合。

**2. 创新评价方式：**

- 构建"16个工单+4个里程碑"的分阶段评价体系，从工单完成度、代码规范度、项目交付物等多个维度评估学生能力。
- 引入"学生成果展示会"和"企业导师评价"等第三方评价机制，确保评价的科学性与公正性。

**3. 创新教学方法的融合应用：**

- 将问题式学习（PBL）、案例教学法、六步教学法及建构主义理论有机融合，应用于课程重点（如数据结构、网络协议仿真）与难点（如复杂项目设计、性能优化）的讲解。
- 遵循"具体-抽象-具体"的认知规律，以工业数据处理需求为导向，通过虚拟产线案例与真实编程实践，帮助学生深刻理解编程原理。

### （五）可持续发展

**1. 技术发展前沿衔接：**

面向工业5.0与AI时代发展趋势，追踪Python在数据科学、机器学习、边缘计算等前沿领域的应用进展。每学期持续更新教学案例，在保留核心编程训练（如基础语法、数据处理、网络通信）的基础上，融入行业新技术内容（如异步编程框架Asyncio、微服务框架FastAPI、边缘计算框架MicroPython等）。

**2. 智能化学习平台演进：**

基于工业互联网的学习平台，集成代码自动批改、AI辅导、实时反馈等智能功能。建设"虚拟产线云实验室"，让学生可以随时随地进行数据处理与编程实验，同步记录学习进度与成长轨迹。

**3. 可持续能力发展路径：**

构建"Python编程基础→数据分析与可视化→机器学习应用→工业互联网完整系统"的递进式学习路径。本课程奠定编程与数据处理基础，后续课程将编程技能融合为工业应用模块（如实时数据处理、智能预测、决策支持系统），供产业实践调用，实现"编程基础—工业应用—创新创业"的终身学习发展链条。

## 三、教学内容

### （一）教学方式

**1. 理实一体教学：** 通过课堂讲解基础知识，结合实际工业案例讨论。

课堂中讲解Python编程基础与网络通信原理（包括变量类型、数据结构、网络协议等），结合工业或民用数据处理实际案例，组织学生研讨理论在代码中的应用场景、解决思路及方案可行性，实现理论与实践融合，帮助学生掌握编程规范并建立"理论指导编程、实践反哺理论"的专业思维。

**2. 仿真驱动学习：** 利用软件仿真工具模拟工业场景，增强学生对编程应用的理解。

选取虚拟产线、网络通信、KPI计算等工业应用场景，用Python仿真库完整演示数据采集→处理→展示的全流程，讲解编程如何解决工业实际问题（如传感器数据噪声消除、网络消息丢失重传、数据异常检测等），帮助学生理解编程的工业价值。

**3. 项目实训教学：** 通过小组项目，提高学生动手能力与团队协作能力。

以模拟或真实数据处理项目为载体（如虚拟产线24小时数据采集项目、班次OEE分析项目、工业互联网仪表板设计项目等），组织3-5人小组完成全流程项目任务：需求分析→方案设计→代码实现→测试验证→成果展示，同步完成技术文档（架构设计图、代码说明书）与项目报告。通过实操巩固技能，在团队协作中培养沟通协调、标准执行及解决复杂问题的综合能力。

**4. 分层学习支持：** 采用ABC三层分层策略，为不同学习水平的学生提供差异化学习路径。

- **C层（学习困难）：** 提供现成的代码框架与详细的运行步骤，学生通过修改参数、运行代码、理解输出来掌握基础概念。
- **B层（正常学习）：** 提供代码模板与关键算法提示，学生需要自主完成部分代码编写与功能实现。
- **A层（快速学习）：** 仅提供需求描述与参考资料，学生需要从零开始设计与编写完整的程序，可进行功能扩展与优化。

## 五、学习评价

### （一）课程评价

**1. 评价理念：**

本课程从学习过程和学习结果两方面进行考核，采用"成果导向、学生中心"的理念，以学生最终的学习成果（如完成一套规范的Python脚本、实现虚拟产线数据管道、参与编程竞赛）为出发点，设计教学与评价。

**2. 评价方式：**

构建"过程性评价与终结性评价相结合、知识考核与能力考核相融合"的多样考评体系，评价内容涵盖：

- 课堂知识回顾（如编程概念问答、逻辑分析发言）
- 课后作业（如代码编写、报告撰写）
- 课中引导启发（如问题回答的逻辑性、创新思路的提出）
- 实训实践（如代码规范性、功能完成的质量、测试覆盖率）
- 职业技能资格证书考取、技能大赛参与等

**3. 评分方式：**

根据过程性考核结果，参照学生参与学习的热情、工作的态度、独立思考、勇于发言，综合分析问题和解决问题的能力，学习资料与软件工具应用，出勤率，代码规范性、学习任务完成效果等多方面情况，综合评价学生的学习成绩。

## 24. nbgrader 原生作业系统 (v2.4 新增)

### 概述

JupyterHub 已安装 **nbgrader 0.9.5**，提供原生的作业分发、收集、自动评分和反馈功能，替代了之前的手动 code_grader.py。

### 教师操作流程

```bash
cd ~/work/nbgrader

# 1. 创建作业（在 source/ 目录下创建 Notebook）
#    在 JupyterLab 中使用 nbgrader 工具栏标记单元格类型:
#    - 答案区（Solution）: 学生需要填写的代码
#    - 测试区（Test）: assert 断言（自动评分用）
#    - 只读区（Read-only）: 题目描述

# 2. 生成学生版（自动去除解决方案）
python3 -m nbgrader generate_assignment ps1

# 3. 发布作业到 exchange
python3 -m nbgrader release_assignment ps1

# 4. 查看已发布的作业
python3 -m nbgrader list

# 5. 学生提交后，自动评分
python3 -m nbgrader autograde ps1

# 6. 生成反馈
python3 -m nbgrader generate_feedback ps1
python3 -m nbgrader release_feedback ps1

# 7. 导出成绩 CSV
python3 -m nbgrader export
```

### 学生操作流程

```bash
cd ~/work/nbgrader

# 1. 查看可用作业
python3 -m nbgrader list

# 2. 获取作业
python3 -m nbgrader fetch ps1

# 3. 完成作业后提交
python3 -m nbgrader submit ps1
```

### nbgrader 元数据要求

每个 nbgrader 单元格需要完整的 v3 元数据:
- `grade`: True/False（是否评分）
- `solution`: True/False（是否答案区）
- `task`: False
- `locked`: True/False（是否锁定）
- `points`: 浮点数（分值）
- `grade_id`: 唯一标识符
- `schema_version`: 3
- `cell_type`: "code"

### Exchange 目录

| 路径 | 说明 |
|------|------|
| `~/work/nbgrader/exchange/` | 共享交换目录 |
| `exchange/default/outbound/` | 教师发布的作业 |
| `exchange/default/inbound/` | 学生提交的作业 |
