## 三、教学内容

### （一）教学方式

#### 1. 理实一体教学

通过课堂讲解核心概念，结合代码演示与学生实操，实现"讲→演→练"的闭环。每个知识点都配有真实的工业场景案例，将抽象编程概念具体化。

**实现方式**：

- 讲解阶段（15分钟）：讲解语言特性或算法概念，结合类比帮助理解
- 演示阶段（15分钟）：教师现场编码展示，强化代码规范与调试技巧
- 实践阶段（25分钟）：学生通过任务式实验立即应用，完成可运行的代码

**案例融合**：每堂课都围绕工业场景设计，例如：

- "Python数据类型" → 工业设备采样数据的存储形式
- "字典与JSON" → 工业协议消息的解析
- "列表与数据处理" → 传感器数据的批量转换

#### 2. 项目驱动学习

将课程内容组织为若干个递进式、任务化的"工单项目"，每个工单都是完整的、可展示的、有实际价值的代码作品。

**工单特征**：

- 规模：200-500行代码
- 产出：完整的.py脚本 + 使用说明文档 + 测试报告
- 场景：模拟真实的工业应用（数据采集、处理、分析）
- 评价：按代码规范、功能完整性、创新性评分

**工单层级**：

- L1（入门）：单个知识点的直接应用
- L2（进阶）：多个知识点的综合应用
- L3（挑战）：引入新工具库或复杂逻辑的自主探索

#### 3. 协同学习与小组项目

每2周组织一次小组项目（2-3人），要求分工明确、代码共享、定期汇报。

**协同机制**：

- 代码审查：小组互相审阅彼此代码，提出改进意见
- 知识分享：每周安排学生轮流讲解一个知识点（5分钟）
- 问题协作：遇到难题时，以小组为单位集体讨论与解决

#### 4. 自主学习与文档驱动

鼓励学生阅读官方文档、参考案例代码、使用搜索引擎自助解决问题。

**资源支持**：

- Python官方文档（中文版）
- 推荐教材：《Python从入门到精通》《流畅的Python》
- 在线平台：LeetCode、HackerRank（Python题库）
- 教师编写的代码注释库与最佳实践指南

##### **任务0.3：函数与代码复用（第3-4周，8课时）**

**学习目标**：

- 知识：掌握函数的定义、调用、参数、返回值；理解变量作用域与函数递归
- 能力：能够设计可复用的函数；能够进行代码模块化；能够使用标准库函数
- 素质：培养模块化设计思想与重用意识

**学习流程**：

1. **函数基础**（2课时）
   
   - 函数的定义与调用（def关键字）
   - 参数类型：位置参数、默认参数、*args、**kwargs
   - 返回值与return语句
   - 函数文档字符串（docstring）的编写

2. **作用域与高级特性**（2课时）
   
   - 本地作用域、全局作用域、闭包概念
   - global 和 nonlocal 关键字
   - 函数递归与递归深度限制
   - Lambda表达式与匿名函数

3. **标准库函数与模块**（2课时）
   
   - 内置函数：map()、filter()、reduce()、sorted()
   - 常用模块：math、random、datetime、time
   - 导入模块的三种方式与最佳实践
   - 自定义模块与包（__init__.py）

4. **函数设计最佳实践**（2课时）

## 24. nbgrader 原生作业系统 (v2.4 新增)

### 概述

JupyterHub 已安装 **nbgrader 0.9.5**，提供原生的作业分发、收集、自动评分和反馈功能，替代了之前的手动 code_grader.py。

### 教师操作流程

```bash
cd ~/work/nbgrader

# 1. 创建作业（在 source/ 目录下创建 Notebook）
#    在 JupyterLab 中使用 nbgrader 工具栏标记单元格类型:
#    - 答案区（Solution）: 学生需要填写的代码
#    - 测试区（Test）: assert 断言（自动评分用）
#    - 只读区（Read-only）: 题目描述

# 2. 生成学生版（自动去除解决方案）
python3 -m nbgrader generate_assignment ps1

# 3. 发布作业到 exchange
python3 -m nbgrader release_assignment ps1

# 4. 查看已发布的作业
python3 -m nbgrader list

# 5. 学生提交后，自动评分
python3 -m nbgrader autograde ps1

# 6. 生成反馈
python3 -m nbgrader generate_feedback ps1
python3 -m nbgrader release_feedback ps1

# 7. 导出成绩 CSV
python3 -m nbgrader export
```

### 学生操作流程

```bash
cd ~/work/nbgrader

# 1. 查看可用作业
python3 -m nbgrader list

# 2. 获取作业
python3 -m nbgrader fetch ps1

# 3. 完成作业后提交
python3 -m nbgrader submit ps1
```

### nbgrader 元数据要求

每个 nbgrader 单元格需要完整的 v3 元数据:
- `grade`: True/False（是否评分）
- `solution`: True/False（是否答案区）
- `task`: False
- `locked`: True/False（是否锁定）
- `points`: 浮点数（分值）
- `grade_id`: 唯一标识符
- `schema_version`: 3
- `cell_type`: "code"

### Exchange 目录

| 路径 | 说明 |
|------|------|
| `~/work/nbgrader/exchange/` | 共享交换目录 |
| `exchange/default/outbound/` | 教师发布的作业 |
| `exchange/default/inbound/` | 学生提交的作业 |
