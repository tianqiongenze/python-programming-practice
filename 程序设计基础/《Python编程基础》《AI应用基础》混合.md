### （二）课程性质与定位

本课程为对接工业互联网产业发展需求、适应高职教育改革，贯彻以培养高职学生实践技能为重点、基础理论与实际应用相结合的指导思想，力求体现精炼与实用。Python编程基础课程是工业互联网应用专业中具有重要应用价值的一门专业基础课程。

其内容涵盖**Python编程基础、数据结构、工业场景仿真、网络通信原理、工业数据处理**等核心模块，实践性突出。既要求学生掌握Python编程基础理论与软件操作原理，也强调结合**工业数据采集、网络通信、实时数据处理**等工业互联网领域实际应用需求，提升学生的编程实践应用能力。

在教学过程中，应依据工业互联网应用专业学生的知识基础与**工业网络运维、数据采集、边缘计算**等岗位实际需求，合理组织教学内容。采用适宜的教学方法，实现教、学、练一体化，注重理论知识与编程实践的融合，构建"在学习中开展编程与数据处理实践、在实践中深化编程知识学习、以虚拟工业数据采集与处理项目为驱动"的教学模式。

通过16个工单的逐级递进，从**基础编程→数据结构→网络通信→数据处理**的完整链路，帮助学生掌握工业互联网场景下的**数据采集、清洗、处理、可视化**等核心技能，为后续《AI应用基础》课程的**机器学习与预测维护**学习奠定扎实的编程与数据处理基础。

### （三）课程基本教学理念

**1. 工学结合与岗位对接：** 课程结构以工业互联网运维、数据采集、边缘计算等岗位实际需求为核心逻辑，深度对接行业岗位的**数据采集、清洗、分析、传输**场景。通过设计真实项目化学习模块（如虚拟产线数据采集项目、班次生产数据统计项目、工业互联网仪表板设计项目等），让学生在完成具体数据处理任务的过程中，将编程理论知识与Python工具有机融合，系统提升学生的数据处理能力及岗位适配的编程实操能力。

**2. 理论与实践相融：** 坚持"理论为实践奠基、实践为理论赋能"的原则，在理论教学中嵌入实践案例（如变量类型结合传感器数据、条件分支结合数据过滤、网络通信结合工业协议MQTT等），在实践教学中强化理论支撑。通过"理论讲解→应用案例→代码实现→结果验证"的闭环教学流程，确保每个学生都能将所学编程理论知识应用于实际工业数据处理，在实操中检验代码的正确性，深化对编程概念的理解。

**3. 自主学习与探索：** 以"激发兴趣、引导探索"为导向，通过设置开放性问题（如"如何快速处理100万条传感器数据？"）、提供个性化学习资源（如Python官方文档、开源项目代码库、工业应用案例集），鼓励学生主动探索编程新知。在项目实施过程中，教师从"主导者"转变为"引导者"，只提供关键编程思路和资源支持，让学生独立完成代码设计、调试验证、结果总结等环节，逐步培养其独立思考能力、自我解决编程问题能力及创新编程思维。

**4. 网络课程深度协同：** 本课程与《计算机网络基础》同步进行，形成"互补螺旋"式学习路径。在第1-8周，Python课程与网络课程深度联动，实现"一个变量=一个数据包""一个函数=一次网络通信""一个JSON数据=网络报文"的类比学习。通过设立**联合讲座（每2周一次60分钟）**和**联合答辩（第8周）**，使学生深刻理解编程与网络通信的融合，为工业互联网技术的学习奠定坚实基础。

**5. 仿真驱动的零硬件方案：** 采用创新的"软件仿真工业场景"方案，设计**三大仿真库**（工业数据仿真库、网络通信仿真库、工业KPI计算库），让学生在无需任何硬件设备的条件下，完整学习工业数据流从采集→传输→处理→展示的全链路。通过虚拟产线系统仿真，学生可以体验真实工业场景，同时大幅降低教学成本，实现教学资源的最优配置。

**6. 赛证课企融合提升能力：** 以工学结合、能力递进为核心思路设计学习情境，课程从工业领域的编程与数据处理应用需求出发，按照"基础编程—数据结构—网络通信—数据处理"的由简到难逻辑搭建内容框架。通过"教师引导—学生自主探究—小组协作完成"的模式，让学生在完成编程任务或项目的过程中，逐步实现对编程工作流程的完整认识。同时，引导和辅助学生参与职业技能竞赛、考取职业资格证书（如"Python开发者认证证书""数据分析工程师证书"）等实践活动，将课堂学习与竞赛、考证有机融合，以赛促学、以证验学。

**7. 分层教学与个性化发展：** 采用ABC三层分层教学策略，根据学生的学习进度与能力水平，提供不同难度的学习任务。C层（学习困难）：运行现成代码，理解逻辑；B层（正常学习）：修改模板，完成标准任务；A层（快速学习）：独立编写，探索扩展。每个工单都有三个层级的学习路径，确保"没有学不会的学生，只有教不好的老师"。

## 二、教学目标

### （一）知识目标

1. **掌握Python编程基础：** 理解变量、数据类型、控制流（条件分支、循环）、函数、模块等核心编程概念，理解编程语言的逻辑思维方式。

2. **理解数据结构与序列化：** 掌握列表、字典、元组、集合等Python数据结构，理解JSON、CSV等数据序列化在网络通信与数据处理中的作用。

3. **认知网络通信基础：** 结合网络课程，理解TCP/UDP、HTTP、MQTT等协议原理，理解网络基础概念与编程语言的关联。

4. **掌握工业数据处理技能：** 理解文件I/O操作原理，掌握Pandas库进行数据清洗与分析，学会处理工业场景中的**时间序列数据、异常数据、缺失数据**。

5. **理解工业KPI计算：** 掌握OEE（设备综合效率）、MTBF（平均故障间隔）等工业关键指标的计算原理与应用。

### （二）能力目标

1. **独立编写程序的能力：** 能编写50行以上的完整Python脚本，掌握代码调试与异常处理。

2. **数据处理与分析能力：** 能用Pandas进行数据清洗、转换、聚合与分析，能用Pyecharts进行数据可视化，能生成工业KPI报告。

3. **工业场景应用能力：** 能模拟传感器数据采集，能设计网络通信流程，能完成"虚拟产线数据管道"开发。

4. **工程思维与问题解决能力：** 能分析复杂工业问题，能设计合理的编程方案，能用代码表达与验证工程概念。

5. **自主学习与创新能力：** 能查阅官方文档自学新技术，能参与编程竞赛与考证。

### （三）素质目标

**1. 编程规范意识与严谨态度：**

在日常学习与编程实践中养成严谨的代码编写习惯，遵循PEP8代码规范，强调"代码不仅要能运行，更要易于被他人理解与维护"的职业素养。培养对编程错误的敏感性，能够细致地进行代码审查与测试，形成"严谨编程、安全第一"的职业精神。

**2. 团队协作与沟通能力：**

在小组项目中主动承担适当的分工任务，能积极参与代码评审（code review），学会清晰地向队友讲解自己的编程思路。能虚心接纳他人的改进建议，形成互相支持、共同进步的团队文化。培养跨专业沟通能力，能与网络课程的学生、产业实践的工程师进行有效的技术交流。

**3. 工业数据安全与法规意识：**

培养对数据安全、隐私保护的重视，理解工业数据的敏感性与价值，遵守数据存储与传输的安全规范。了解软件知识产权、开源协议等法律问题，树立尊重他人劳动成果、合法使用开源代码的法律意识。

**4. 工业互联网融合意识：**

通过虚拟产线、网络协同等教学设计，帮助学生理解编程技术在工业互联网中的关键作用，树立"编程是工业互联网的基石"的认识，培养对工业技术发展的关注与思考，为后续《AI应用基础》课程的学习做思想与技术准备。

## 三、教学内容

### （一）教学方式

**1. 理实一体教学：** 通过课堂讲解基础知识，结合实际工业案例讨论。

课堂中讲解Python编程基础与网络通信原理（包括变量类型、数据结构、网络协议等），结合工业或民用数据处理实际案例，组织学生研讨理论在代码中的应用场景、解决思路及方案可行性，实现理论与实践融合，帮助学生掌握编程规范并建立"理论指导编程、实践反哺理论"的专业思维。

**2. 仿真驱动学习：** 利用软件仿真工具模拟工业场景，增强学生对编程应用的理解。

选取虚拟产线、网络通信、KPI计算等工业应用场景，用Python仿真库完整演示数据采集→处理→展示的全流程，讲解编程如何解决工业实际问题（如传感器数据噪声消除、网络消息丢失重传、数据异常检测等），帮助学生理解编程的工业价值。

**3. 项目实训教学：** 通过小组项目，提高学生动手能力与团队协作能力。

以模拟或真实数据处理项目为载体（如虚拟产线24小时数据采集项目、班次OEE分析项目、工业互联网仪表板设计项目等），组织3-5人小组完成全流程项目任务：需求分析→方案设计→代码实现→测试验证→成果展示，同步完成技术文档（架构设计图、代码说明书）与项目报告。通过实操巩固技能，在团队协作中培养沟通协调、标准执行及解决复杂问题的综合能力。

**4. 分层学习支持：** 采用ABC三层分层策略，为不同学习水平的学生提供差异化学习路径。

- **C层（学习困难）：** 提供现成的代码框架与详细的运行步骤，学生通过修改参数、运行代码、理解输出来掌握基础概念。
- **B层（正常学习）：** 提供代码模板与关键算法提示，学生需要自主完成部分代码编写与功能实现。

### （二）课程性质与定位

本课程为对接工业互联网产业发展需求、适应高职教育改革，贯彻以培养高职学生实践技能为重点、基础理论与实际应用相结合的指导思想，力求体现精炼与实用。AI应用基础课程是工业互联网应用专业中具有重要战略意义的一门专业基础课程。

其内容涵盖**机器学习基础、特征工程、故障诊断、时间序列预测、剩余使用寿命（RUL）预测、模型评估与优化**等核心模块，实践性突出。既要求学生掌握工业AI理论基础与建模方法，也强调结合**工业设备故障诊断、预测维护、状态监测**等工业互联网领域实际应用需求，提升学生的机器学习应用能力。

在教学过程中，应依据工业互联网应用专业学生的知识基础与**工业数据分析、设备预测维护、状态监测**等岗位实际需求，合理组织教学内容。采用适宜的教学方法，实现教、学、练一体化，注重理论知识与建模实践的融合，构建"在学习中开展机器学习与建模实践、在实践中深化算法与模型知识学习、以虚拟产线故障预测与预测维护项目为驱动"的教学模式。

通过12个工单的逐级递进，从**特征工程→分类模型→时间序列预测→综合应用**的完整链路，帮助学生掌握工业AI场景下的**设备故障诊断、异常检测、寿命预测**等核心技能，为后续《工业互联网应用系统》课程的系统集成与部署学习奠定扎实的机器学习基础。

### （三）课程基本教学理念

**1. 工业AI赋能与应用导向：** 课程结构以工业预测维护、故障诊断、状态监测等岗位实际应用为核心逻辑，深度对接行业岗位的**数据驱动决策、智能预测、提前预警**场景。通过设计真实项目化学习模块（如轴承故障诊断项目、电机温度异常检测项目、设备RUL预测项目等），让学生在完成具体建模任务的过程中，将机器学习理论知识与Scikit-learn、Prophet等工具有机融合，系统提升学生的建模应用能力及岗位适配的工业AI实操能力。

**2. 理论与实践相融：** 坚持"理论为实践奠基、实践为理论赋能"的原则，在理论教学中嵌入实践案例（如特征工程结合传感器数据、分类模型结合故障诊断、时间序列模型结合温度趋势预测等），在实践教学中强化理论支撑。通过"理论讲解→应用案例→模型实现→结果验证"的闭环教学流程，确保每个学生都能将所学机器学习理论知识应用于实际工业预测维护，在实操中检验模型的有效性，深化对算法原理的理解。

**3. 自主学习与问题驱动：** 以"激发兴趣、引导探索"为导向，通过设置开放性问题（如"如何预测设备何时会故障？""如何识别异常的传感器信号？"）、提供个性化学习资源（如Scikit-learn官方教程、Kaggle竞赛案例、工业预测维护数据集），鼓励学生主动探索机器学习新知。在项目实施过程中，教师从"主导者"转变为"引导者"，只提供关键建模思路和资源支持，让学生独立完成**特征工程、模型训练、参数优化、结果评估**等环节，逐步培养其独立思考能力、自我解决建模问题能力及创新AI思维。

**4. 赛证课企融合提升能力：** 以工学结合、能力递进为核心思路设计学习情境，课程从工业领域的AI应用需求出发，按照"特征工程—分类模型—回归模型—时间序列预测"的由简到难逻辑搭建内容框架。通过"教师引导—学生自主探究—小组协作完成"的模式，让学生在完成建模任务或项目的过程中，逐步实现对机器学习工程工作流程的完整认识。同时，引导和辅助学生参与数据竞赛（如Kaggle、天池竞赛）、考取职业资格证书（如"数据分析工程师证书""工业AI应用工程师证书"）等实践活动，将课堂学习与竞赛、考证有机融合，以赛促学、以证验学。

**5. 分层教学与个性化发展：** 采用ABC三层分层教学策略，根据学生的学习进度与能力水平，提供不同难度的学习任务。C层（学习困难）：运行现成代码，理解模型逻辑；B层（正常学习）：修改参数，完成标准建模任务；A层（快速学习）：自主设计特征、尝试高级算法、模型对比优化。每个工单都有三个层级的学习路径，确保"没有学不会的学生，只有教不好的老师"。

## 二、教学目标

### （一）知识目标

1. **理解机器学习基础：** 理解监督学习、无监督学习、强化学习的基本概念，理解模型选择、交叉验证、过拟合等核心概念。

2. **掌握特征工程原理：** 掌握**特征提取、特征选择、特征缩放**等技能，理解特征工程对模型性能的关键影响，学会分析工业数据的特性。

3. **理解分类与回归模型：** 掌握**决策树、随机森林、支持向量机、梯度提升**等常用算法的原理与应用场景，理解模型选择的依据。

4. **掌握时间序列预测：** 掌握**ARIMA、Prophet、LSTM**等时间序列模型，学会处理**趋势、季节性、异常值**等时间序列特性。

5. **理解工业应用场景：** 掌握**故障诊断、异常检测、剩余寿命预测、状态监测**等工业预测维护的典型任务，理解工业AI的实际价值。

6. **掌握模型评估指标：** 掌握**准确率、精准率、召回率、F1分数、AUC-ROC、RMSE、MAE**等评估指标，理解不同指标的适用场景。

7. **理解工业标准与规范：** 掌握**ISO 13373故障诊断标准、IEC 61670预测维护标准**的基本要求，理解标准指导下的工业AI应用。

### （二）能力目标

1. **数据预处理与特征工程能力：** 能进行**缺失值处理、异常值检测、数据标准化、特征编码**等数据预处理，能独立完成**特征提取和特征选择**。

2. **模型训练与优化能力：** 能用Scikit-learn进行**模型选择、参数调优、交叉验证**，能对比不同算法的性能，能进行**超参数优化**。

3. **分类问题解决能力：** 能独立完成**故障诊断、故障分级、设备状态分类**等分类任务，能设计合理的分类方案，能进行**类别不平衡处理**。

4. **时间序列预测能力：** 能用Prophet进行**短期和长期预测**，能进行**异常检测和异常值处理**，能建立**多步预测模型**。

5. **模型评估与验证能力：** 能进行**模型性能评估、交叉验证、学习曲线分析**，能识别**过拟合和欠拟合**现象，能提出改进方案。

6. **工业应用集成能力：** 能将机器学习模型**集成到实际工业系统**中，能进行**模型部署和推理**，能设计**预测结果的告警机制**。

7. **自主学习与创新能力：** 能查阅文献自学新的机器学习算法，能对标准工业数据集进行建模实验，能参与数据竞赛与考证。

### （三）素质目标

**1. 严谨的数据科学素养与专业态度：**

在机器学习建模过程中养成严谨的态度，对数据质量、模型假设、预测结果等保持科学的怀疑精神。强调"数据会说谎"的理念，教导学生在应用模型结果时要进行**充分的可解释性分析和业务验证**，不盲目迷信模型，形成"科学、谨慎、负责任"的数据科学职业精神。

**2. 数据隐私与伦理意识：**

**3. 团队协作与沟通能力：**

## 三、教学内容

### （一）教学方式

**1. 项目驱动学习：** 通过真实的工业预测维护项目，从应用出发，倒推所需的算法与模型。

课堂中以"故障诊断项目""设备RUL预测项目"为载体，先展示预期的最终结果（如"预测设备还能运行168小时"），然后反向讲解实现这个结果需要的特征工程、算法选择、参数优化等步骤。这样学生从一开始就能理解"我为什么要学这个算法"，学习动力更强。

**2. 案例分析学习：** 利用真实的工业数据集和经典案例，增强学生对机器学习工业应用的理解。

选取轴承故障诊断、电机温度异常检测、设备寿命预测等真实工业案例，详细讲解**数据特性分析、特征工程设计、模型选择依据、结果解释方法**等，帮助学生理解"在真实工业场景中，我们如何做决策"。

**3. 建模实战教学：** 通过小组建模项目，提高学生的算法应用能力与工业问题解决能力。

以真实或模拟工业数据处理为载体（如"某企业轴承故障数据集""设备运行参数时间序列"等），组织3-5人小组完成全流程建模任务：需求分析→特征工程→模型选择→参数优化→模型评估→结果解释，同步完成建模文档（特征说明书、模型选择依据、性能报告）。通过实操提升建模能力，在团队协作中培养工程意识与沟通能力。

**4. 分层学习支持：** 采用ABC三层分层教学策略，为不同学习水平的学生提供差异化学习路径。

- **C层（学习困难）：** 提供现成的特征集和模型框架，学生通过调整参数、对比效果来理解模型逻辑。
- **B层（正常学习）：** 提供数据和建模目标，学生需要自主进行特征工程、模型选择、参数优化。
- **A层（快速学习）：** 仅提供原始数据，学生需要从零开始进行问题分析、特征设计、算法对比、结果优化。

## 24. nbgrader 原生作业系统 (v2.4 新增)

### 概述

JupyterHub 已安装 **nbgrader 0.9.5**，提供原生的作业分发、收集、自动评分和反馈功能，替代了之前的手动 code_grader.py。

### 教师操作流程

```bash
cd ~/work/nbgrader

# 1. 创建作业（在 source/ 目录下创建 Notebook）
#    在 JupyterLab 中使用 nbgrader 工具栏标记单元格类型:
#    - 答案区（Solution）: 学生需要填写的代码
#    - 测试区（Test）: assert 断言（自动评分用）
#    - 只读区（Read-only）: 题目描述

# 2. 生成学生版（自动去除解决方案）
python3 -m nbgrader generate_assignment ps1

# 3. 发布作业到 exchange
python3 -m nbgrader release_assignment ps1

# 4. 查看已发布的作业
python3 -m nbgrader list

# 5. 学生提交后，自动评分
python3 -m nbgrader autograde ps1

# 6. 生成反馈
python3 -m nbgrader generate_feedback ps1
python3 -m nbgrader release_feedback ps1

# 7. 导出成绩 CSV
python3 -m nbgrader export
```

### 学生操作流程

```bash
cd ~/work/nbgrader

# 1. 查看可用作业
python3 -m nbgrader list

# 2. 获取作业
python3 -m nbgrader fetch ps1

# 3. 完成作业后提交
python3 -m nbgrader submit ps1
```

### nbgrader 元数据要求

每个 nbgrader 单元格需要完整的 v3 元数据:
- `grade`: True/False（是否评分）
- `solution`: True/False（是否答案区）
- `task`: False
- `locked`: True/False（是否锁定）
- `points`: 浮点数（分值）
- `grade_id`: 唯一标识符
- `schema_version`: 3
- `cell_type`: "code"

### Exchange 目录

| 路径 | 说明 |
|------|------|
| `~/work/nbgrader/exchange/` | 共享交换目录 |
| `exchange/default/outbound/` | 教师发布的作业 |
| `exchange/default/inbound/` | 学生提交的作业 |
